# DeskBox Mobile 0.6.0 (7)

Native SwiftUI iOS 17 client. The unsigned iPhoneOS arm64 IPA has passed a real GitHub macOS/Xcode build. Keep the original signing team and Bundle ID for an in-place update.

Cloud account sync works across networks while DeskBox is running on Windows. Local TLS pairing remains available.

Mobile AI now relays through the authorized Windows provider, with live stages, resumable responses and read-only task/project/incident/document tools. Chinese speech recognition, reply speech and continuous foreground voice conversation are implemented. Physical-device microphone and audio behavior still require verification.

See [mobile AI and voice](../../docs/MOBILE-AI-0.6.0.md), [V3 status](../../docs/V3-0.6.0-STATUS.md), and [pairing instructions](../../docs/手机配对与同步说明.md).
