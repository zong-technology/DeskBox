## 二、真正实现并已验证的功能

- 桌面分类、隐藏/恢复、拖放、多视图、托盘与单实例。
- 文件索引、筛选、收藏、最近、标签、预览、磁盘分析、批量重命名、移动/复制、删除到备份和撤销。
- AI&SI 多服务商 CRUD、默认服务商、模型、超时、重试、DPAPI 密钥加密、真实 HTTP/SSE、9 类错误分类、多轮对话、取消、重生成与历史保存。
- AI 工具调用闭环：解析白名单工具、授权目录、危险操作确认、真实执行、结果回灌、日志与循环上限。
- 自动化 v2：顺序节点、条件、AI 节点、数据传递、失败策略、有限重试、超时、取消、并发限制、节点记录；页面可创建 v2 模板、复制、启停、预演、后台执行和取消。
- Open-Meteo 当前天气、体感、湿度、风、降水、24 小时与 6 日预报；城市唯一 ID/经纬度搜索与切换；缓存/离线来源明确标记。
- 摄氏/华氏单位真实切换；天气刷新周期真实影响 UI 定时器、内存缓存和磁盘缓存。
- 任务 CRUD、优先级、截止、单次提醒；提醒不再阻塞 UI，持久化到通知中心，可回看与标记已读。
- CPU、内存、磁盘、网络真实系统指标；剪贴板事件监听与敏感内容屏蔽。
- 统一工作记录页面：AI、自动化、文件、任务、配置、通知、系统与错误筛选/搜索/详情/清理。
- 数据备份与恢复：备份全部数据（排除备份目录自身）；恢复在下次启动前执行，并先创建恢复前安全快照。
- Engineering Edition 驾驶舱：系统遥测、任务风险、置顶项目、最近文件与快捷任务总线。
- 工程项目舱：持久化 PLC/DCS/SCADA/CSV 项目路径、客户/系统/备注、置顶和最近打开；显式选择的项目目录加入文件索引。
- 工程工具矩阵：4–20mA、Pt100、压力/温度单位、Siemens S7 地址、Modbus Float 四种字节序、DNS/Ping/TCP 端口诊断。
- 制药验证工具：URS/DQ/IQ/OQ/PQ、CSV 风险评估、21 CFR Part 11 Markdown 清单与任务生成。
- AI&SI 六种工程模式与四个确定性工具；Temperature/Max Tokens 已从 UI 真实传入请求。
- Cyber 工程主题、Ctrl+K 命令矩阵、Ctrl+Alt+Space 全局呼出，以及第二实例唤醒已运行实例。

## 三、本轮审查发现并修复的问题

| 级别 | 问题 | 处理结果 |
|---|---|---|
| P0 | 启动阶段和主窗体各启动一套监控/工作流调度 | 改为主窗体唯一持有持续服务；启动画面只做真实一次性验证 |
| P0 | 退出只停止 3 个 UI Timer，未取消 AI/工作流、监控与剪贴板 | 完整生命周期清理并新增 14 项验收 |
| P0 | `install.ps1` 每次升级会把 `dist\data` 覆盖到用户数据 | 禁止安装开发数据；升级保持用户数据不变，并保留上一版 EXE |
| P1 | 工作流启动 Timer 只保存在局部变量，可能被 GC 提前回收 | 改为字段强引用并在停止调度时释放 |
| P1 | ChatService 未接入主工作流引擎，`workflow.run` 工具不可用 | 接入同一引擎实例 |
| P1 | 工作流通知/危险确认没有 UI 注入 | 接入通知中心和 fail-closed 确认通道 |
| P1 | 导航“工作记录”实际显示文件操作历史 | 新增统一记录页，原文件历史保留独立入口 |
| P1 | 任务提醒只有打开任务页才运行，并使用阻塞 MessageBox | 提升为主窗体全局提醒与持久化非阻塞通知 |
| P1 | 备份只有复制，没有恢复入口 | 新增验证、安排恢复、启动前恢复与安全快照 |
| P1 | 天气刷新设置只保存，逻辑仍硬编码 10/60 分钟 | 统一按设置执行，并在失败时使用明确标记的旧缓存 |
| P1 | 华氏度选项保存但不生效 | 天气页与右侧天气卡均真实转换 |
| P1 | 助手仍显示 WorkBuddy，不符合规格的 AI&SI 命名 | 导航、启动画面、聊天、确认框与系统提示统一为 AI&SI |
| P1 | AI 参数栏 Temperature/Max Tokens 仅显示，实际请求固定 0.7 | 改为每会话持久化并真实写入 API 请求 |
| P1 | 工程工作流分散，频繁返回桌面找项目/工具 | 新增默认工程驾驶舱、项目舱、命令矩阵与全局呼出 |

## 四、只有界面或实现仍不完整的部分

- 任意节点图形化编辑器尚未实现；当前页面提供可执行的 v2 模板和管理操作，底层执行器能力完整。
- 文件变化触发器、通用事件触发器尚未实现；当前支持手动、启动和固定间隔触发。
- 周期性任务提醒规则尚未实现；当前是单次本地时间提醒。
- 自动更新未实现，界面明确标注为手动升级。
- 动态界面缩放尚未实现；WinForms 当前使用系统 DPI 缩放。
- 文件索引仍会在启动时加载约 10 MB `index.json`，后续可做分片或惰性加载。
- 只支持 Open-Meteo 单一天气数据源，暂不提供可插拔天气供应商。
- 工程项目舱当前管理本地目录与元数据，不解析 TIA Portal 专有项目格式，也不直接连接生产 PLC。
