# 软件内沉浸全息对话

AI&SI / AI 助手 → 全息 AI 通话，会将当前软件窗口直接切换为投影与下方字幕。没有额外窗体、插件、参数面板、场景菜单或可见工具栏。

首次在「功能与设置 → 全息语音」保存实时服务地址、模型和密钥，后续打开直接读取并连接。密钥由当前 Windows 用户的 DPAPI 加密保存到数据目录的 `realtime-voice.json`；不会以明文写入 JSON，升级保留该文件。保存只检查输入格式，模型权限与服务配额在实际通话时验证。

默认投影为量子光核：独立的三维光点和光丝经透视投影绘制，带多层倾斜轨道、柔光、体积光粒和地面发射光环。实际输入与播放音量驱动响应，倾听、思考与发声使用不同光色。原画角色和星辉粒子可以在常规设置中选择，通话画面中不显示外观选择。

实时字幕包含服务实际返回的用户转写与 AI 回复。Esc 返回软件并关闭会话，Ctrl+M 静音；连接中断后可点击投影重试。缺少已保存的语音服务时显示纯投影及未连接状态，不弹出配置界面，也不启用麦克风。只在用户进入且配置可用时创建语音连接。

反应器、PLC、项目进度、探头演示与服务端场景工具已从全息通话中移除。软件其他工程模块不受影响。

这是屏幕内的实时视觉呈现，无法把普通显示器变成物理空间全息设备；原画角色仍是 2.5D 素材，不声称已重建角色骨骼或口型。

Windows 构建使用 `build.ps1`。隔离检查由 `tools/silverwing-accept.cs` 执行，语音使用模拟传输与音频设备，验证自动连接、取消、设备释放、加密配置、字幕、软件内进入/退出及减少动态。真实服务通话需要有效密钥后在本机验收。
