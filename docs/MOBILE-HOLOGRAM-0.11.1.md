# DeskBox Mobile 0.11.1 · 全息亮屏与误触修复

- 全息连接、倾听、思考和播报期间阻止系统自动锁屏，网络与本地通话共用同一管理路径。退出、进入后台、系统音频打断或连接失败时，恢复进入通话前的自动锁屏设置；再次进入不会把临时亮屏状态当作原设置保存。
- 普通点击投影不再打断回复。需要插话时使用字幕下方的「打断后提问」，静音和退出仍用明确按钮。恢复通话使用「重新连接」，错误和暂停提示同步改为指向该按钮。
- 主动按电源键锁屏或将应用切到后台仍会暂停录音与连接，返回后由用户点击重新连接；本版本不提供锁屏后台录音。
- 新增原生双尺寸交互回归：读取真实 UIKit 自动锁屏开关，覆盖普通点屏、明确打断、进入后台、手动重连、退出及连续两次进入，并分别验证原设置允许锁屏和已经禁用锁屏的情况。预览不访问麦克风、实际模型或生产资料。

保留 0.11.0 的手机独立 AI、本地 / 网络环境、模型配置、名称角色、对话记录及折叠工具。IPA 内部版本 0.11.1/build 13，最低 iOS 17；Apple 本机模型仍需 iOS 26+ 和实际可用的 Apple Intelligence。

安装时沿用原签名团队和 `com.deskbox.mobile` 签名覆盖，不要先卸载。自动化不能代替目标 iPhone 上真实长通话、系统自动锁屏与扬声器 / 蓝牙验收。
