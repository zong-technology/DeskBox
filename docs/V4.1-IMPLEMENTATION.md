## 家中 Windows 虚拟机中继（V4.1）

后台入口为 `DeskBox.exe --bridge`。它复用私人云 HTTPS 同步和手机文本 AI 任务队列，保持原来的手机 AI 只读权限与可信目录控制。它不打开主窗口、不接管桌面，也不启动 LAN 监听。实时双向音频不走这条按任务轮询的队列。

1. 家里的宿主机需持续供电与联网，虚拟机需配置随宿主机启动并禁止自动睡眠。为虚拟机准备 D 盘与专用 Windows 用户。
2. 为该用户设置 `DESKBOX_HOME=D:\DeskBoxBridge\data`。首次用该用户打开 DeskBox 完成现有私人云电脑授权并配置文本 AI 供应商。使用合成数据先验收。正式项目和允许访问的文件须同步或挂载到该虚拟机。云授权和文本密钥由当前用户 DPAPI 保护，需要在虚拟机上重新授权。
3. 退出同一会话的 DeskBox 主窗口，使用同一用户运行 `DeskBox.exe --bridge`。确认云端能处理测试任务后，再配置 Windows 任务计划程序，选择开机触发、使用该用户、用户未登录也运行、失败重启。别用 SYSTEM 或不同用户读取原 DPAPI 凭据。
4. 用 iPhone 提交只读测试任务。分别在笔记本关机、虚拟机远程桌面断开、虚拟机重启后三种状态核对任务和项目同步、失败提示与恢复。现有私人云 HTTPS 中继由虚拟机主动访问，家庭路由器无需为此转发端口。尚未在用户的虚拟机实测。

退出码：2 为未指定 D 盘数据目录，3 为缺少或无法解密的云授权，4 为启动或运行异常，5 为同一会话已有 DeskBox 进程。任务计划和日常运行使用一个专用账户，避免多个会话并发读写同一数据目录。

### 语音供应商

`IRealtimeVoiceProvider` 将输入、输出和事件与 Gemini 协议分开。`GeminiLiveVoiceProvider` 可传入 WSS 地址、模型和 API Key，首选 Google 官方 Gemini Live 端点；兼容端点必须遵守同一 Gemini Live 协议。其他协议（例如 OpenAI Realtime）需另写适配器。适配器采用 16 kHz 输入、24 kHz 输出 PCM16，并解析中断、轮次完成和服务端重连提示。Windows 候选版已在 AI&SI 的实时语音入口接入 16 kHz 麦克风、24 kHz 扬声器队列和输入/播放电平。Gemini 返回中断时重置扬声器缓冲；端点和模型可编辑，密钥目前仅用于当前窗口，也可从本机进程的 GEMINI_API_KEY 环境变量读取。尚未接入手机、后台流式接口、持久化设置或自动重连，未用真实 API Key 联网验收。最终语音密钥由虚拟机保管，手机端不保存长期供应商密钥。 [Google Live WebSocket 文档](https://ai.google.dev/gemini-api/docs/live-api/get-started-websocket)

### 百炼实时语音与模型发现

Windows AI&SI 的「实时语音」默认选千问百炼，仍可切换 Gemini。百炼默认模型是 qwen3.8-omni-flash-realtime。请把 WSS 地址中的 YOUR-WORKSPACE 替换成百炼业务空间 ID，或粘贴对应地域的完整 WSS 地址（去掉 ?model=...，模型 ID 独立填写）。API Key 可在窗口临时输入或由本机 DASHSCOPE_API_KEY 提供。切换供应商保留本次窗口输入，关闭后不持久化密钥。

「获取模型」通过同一工作空间的 HTTPS 模型目录分页获取百炼 Realtime-Omni 模型。官方 Gemini 地址通过 Google 模型目录筛选双向接口；自定义 Gemini 地址仍可手工填写模型 ID。列表不代表该 Key 已获推理配额。未接入 ASR/TTS 专用协议或任意第三方协议。

验证：本地协议样本覆盖 PCM、打断后丢弃旧音频、下一轮恢复和目录筛选。UI 验证默认模型、供应商切换、凭据隔离和工作空间校验。未使用真实百炼 Key 联网验证。

[百炼实时语音](https://help.aliyun.com/zh/model-studio/realtime) · [百炼模型目录](https://help.aliyun.com/zh/model-studio/list-models)

后续语音场景要求（用户确认）：恢复语音开发时，画面应根据对话内容生成。现有受控固定场景仅用于验证交互链路，不能作为生成式场景验收结果。语音暂缓，继续业务页面与部署工作。
