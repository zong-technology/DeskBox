# 不同网络自动同步：最少三步开通

当前推荐：使用你自己的 Cloudflare 账号部署私人 DeskBox 服务。不需要同一 Wi-Fi、VPN 或购买服务器。
脚本、电脑客户端和 iPhone 客户端已准备。2026-11-03 已在自有 Cloudflare 账号部署服务，修复网页登录来源误拦截，并验证真实密码登录及设备授权页面；手机跨网络联测仍待完成。下文保留首次开通流程。

## 1. 注册免费账号

打开 https://dash.cloudflare.com/sign-up ，注册并完成邮箱验证。先使用免费计划，不必为此次验证购买服务器或付费套餐。
服务后续受 Cloudflare Workers / D1 免费额度限制，按实际使用量管理，不承诺无限免费。

## 2. 电脑执行部署脚本

保留项目文件夹结构，在 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\桌面\SureHand_Project\Deepseek\deskbox\tools\deploy-deskbox-cloud.ps1"
```

脚本会打开 Cloudflare 官方授权页，由你登录并授权部署；不会要求你把账号密码或 API 密钥交给我。
如果使用整包 ZIP，先解压，在解压目录打开 PowerShell，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\deploy-deskbox-cloud.ps1` 即可。
如提示选择账号或开通 workers.dev 子域名，选择刚注册的账号并按官方页面完成即可。

脚本会创建或复用 `deskbox-sync-data` 数据库，部署 Worker，并设置随机生成的私人云登录密码。
需要 Node.js 22 或更高版本；本机已有 Node。其他电脑没有 Node 时先安装 https://nodejs.org/ 的 LTS 版本。

完成后记下控制台打印的 `https://…workers.dev` 地址。
私人云账号是 **owner**；首次生成的 **64 位随机密码自动复制到剪贴板**，请立即存入密码管理器，再复制其他内容。
密码不写入项目文件。Cloudflare 登录和 DeskBox 私人云登录是两套权限：前者用于部署，后者用于授权设备。

## 3. 分别登录并授权电脑、手机

1. 浏览器打开刚生成的 workers.dev 地址，用 `owner` 和保存的随机密码登录。
2. 选择“Windows 主电脑”，填写名称，生成并复制连接凭证。
3. 电脑 DeskBox → 手机联动 → **账号云同步**，填写相同 HTTPS 地址；粘贴 Windows 凭证，点击“导入并同步”。
4. 在 iPhone Safari 打开同一服务地址，登录相同私人云账号。选择“iPhone”并授权，点击“导入此 iPhone”，在应用中确认连接。
5. 如果浏览器不能直接打开应用，则复制 iPhone 凭证，手机首页 → 连接设置 → 账号云同步，粘贴并导入。

两端以后无需反复登录或配对。电脑每 15 秒检查云同步，手机在前台自动刷新并上传编辑。
可以让电脑使用公司网络、手机使用蜂窝网络，分别新建/完成任务，验证双向同步。

## 使用与升级

- Windows 使用本批 `dist/cloud-0.3.1/DeskBox.exe`。退出原程序后升级，保留原数据目录；不要删除 `data`。
- iPhone 使用 `dist/ios/DeskBoxMobile-0.3.1-unsigned.ipa`，由你按原签名配置覆盖安装，保持 `com.deskbox.mobile`，不要先卸载。
- 电脑是主工作站。电脑离线时手机可以读取上次云快照，新提交保留手机/云端队列，等待电脑上线确认。
- 当前每个私人服务支持一台主电脑和多台手机。更换主电脑前先撤销旧电脑，并保留/迁移原项目数据。
- 手机锁屏或被系统挂起后不保证持续同步。每日提醒采用系统本地通知；不伪装常驻后台。
- 在网页撤销丢失设备；仅退出网页不会撤销已经授权的应用。
- 程序只增量上传发生版本变化的记录；服务端忽略完全相同的快照，避免反复消耗数据库写入额度。

## 密码遗失、升级与限制

遗失私人云登录密码时，在原项目中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\桌面\SureHand_Project\Deepseek\deskbox\tools\deploy-deskbox-cloud.ps1" -ResetPassword
```

它会换新密码并使网页登录会话失效；已授权设备需要另外在设备页撤销。
正常重跑脚本用于升级，会复用数据库并保留密码，不会删除项目或任务记录。

如果创建数据库时解析输出失败，重新运行即可通过数据库列表复用已创建的库，不要手动删除数据库。
如果区域网络不能访问 workers.dev，需进一步配置你自己的可访问域名或改用可达的托管服务；目前没有做出任何地区的可用性保证。
