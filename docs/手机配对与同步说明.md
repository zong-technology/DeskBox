## 没有 Mac 怎么安装手机端

可使用云端 Mac，或支持 macOS 构建的持续集成服务，运行本仓库的 Xcode 工程，
完成构建与 Apple 签名。TestFlight 分发通常需要 Apple Developer Program 账号，
签名证书、描述文件与 App Store Connect 配置。云端 Mac 和开发者账号可能收费。
这些账号与签名条件尚未在本项目中配置；当前没有可用的已签名 IPA。
Windows 不能单独完成原生 iOS 应用的 Apple 签名与正式分发。

取得已签名并安装好的 DeskBox Mobile 后，再执行下面的配对流程。

## 首次配对

1. 电脑与 iPhone 连接同一可信局域网。电脑可用网线，手机用同路由器的 Wi-Fi。
   访客网络、AP 隔离、VPN 或企业策略可能阻止两台设备互访。
2. 电脑打开 DeskBox → 左侧“手机联动” → “启动 Local Sync”。
   页面应显示 ONLINE、本机地址、TLS 端口及证书指纹。
3. 如 Windows 防火墙提示访问权限，只在你信任的专用网络允许 DeskBox。
   默认同步使用 TCP 47831；发现协议使用 UDP 47830。手工粘贴链接配对不依赖 UDP 发现。
4. 点击“生成配对码”，再点击“复制配对链接”。配对码有效期为 5 分钟，
   只能成功使用一次。重新生成、停止服务或电脑端退出后，旧配对码失效。
5. 将完整链接安全地传到自己的手机。链接格式为：
   `deskbox://pair?host=电脑局域网IP&port=47831&code=六位码&fp=证书SHA256指纹`。
   不要把链接发到公开群组。当前复制功能不会自动把链接发送到手机。
6. 手机打开 DeskBox Mobile → 首页右上角齿轮 → 配对区域，粘贴完整链接并配对。
   出现系统“本地网络”权限提示时允许。
7. 手机状态显示 PAIRED，电脑“设备”列表出现手机，说明设备信任已建立。
8. 默认自动同步开启，配对后自动拉取。状态显示 ONLINE，且项目与任务出现，说明首次同步完成。

手机会核对链接中的证书 SHA-256 指纹，并把访问凭证存入 iOS Keychain。
这里的配对建立的是 DeskBox 数据访问权限；不提供直接 PLC/DCS 控制功能。

## 日常同步与验证

- 电脑保持开机、DeskBox 运行且 Local Sync 为 ONLINE。
- 手机保持前台：每 15 秒检查同步；任务/事件编辑后约 0.9 秒触发上传。请求串行执行。
- 在电脑修改项目或任务后，手机前台下一轮同步刷新；重新打开手机应用也会同步。
- 断网时资料及待上传队列保留；网络恢复自动重试，连续失败逐步退避，最长约 120 秒。
- iOS 挂起或退出应用后不保证持续同步；本版本没有 APNs 后台推送或常驻后台服务。
- 配对凭证保存在 Keychain，正常启动无需重新配对。有效期不足 7 天时在线续为 30 天；已过期或撤销的凭证不能续期。
- 设置保留“立即同步”作为手动补救入口；自动同步可关闭。
- “部分数据未上传或存在冲突”表示仍有未确认上传的内容，不代表同步全部完成。
  冲突处理界面尚未完善，不要靠反复重新配对解决数据冲突。
- 手机端 Incident 记录可进入同步存储，但 Windows 专用事件处理界面尚未交付。

## 故障排查

| 现象 | 操作 |
|---|---|
| 电脑不是 ONLINE | 检查端口占用；查看页面错误与工作记录。服务启动部分失败时会自动清理已启动的部分。 |
| 复制链接按钮不可用 | 先启动服务并重新生成配对码；过期或已使用的配对码不能继续复制。 |
| 手机提示链接无效 | 从电脑重新复制完整链接，不要只粘贴六位码。 |
| PAIRING FAILED | 检查网络、有效期、防火墙和 iOS 本地网络权限，再生成新码。 |
| 地址含 VPN/虚拟网卡 IP | 将链接 host 字段换成电脑 Wi-Fi/以太网在同一路由器下的 IPv4；其他字段保持原样。 |
| 电脑 IP 变化或重装后无法连接 | 在手机连接设置修改主机和端口，保留原设备身份并核对原证书；电脑证书更换、设备撤销或凭证过期才需要重新配对。 |
| 同步失败但本地有新增内容 | 保留手机本地数据，检查电脑服务和网络后重试，不要卸载手机应用。 |
| 设备丢失或不再信任 | 电脑选择设备 → “撤销设备”；该设备原凭证将不能继续同步。 |

## 停止与重新配对

“停止 Local Sync”关闭局域网服务并作废未使用的配对码，保留已信任设备。
以后重新启动服务，已有设备在原地址、原证书且凭证未过期时可继续同步。
“撤销设备”使旧凭证失效；需要恢复访问时，应重新生成配对码并重新配对。

## 不同网络使用（私有网络方案）

1. 在 Windows 与 iPhone 上安装 Tailscale 或 ZeroTier，加入同一个受控私有网络；此步骤需要相应账号和两端配置，项目尚未代为完成。
2. 电脑保持 Local Sync 启动。确认该私有网络允许手机访问电脑的 TCP 47831，Windows 防火墙按实际私有网络策略放行。
3. 手机连接设置填写电脑在该私有网络中的固定 IP 或可解析主机名，以及同步端口。不要填写 `https://`、路径或配对码。
4. 保存地址后会保留原 token 和证书指纹，通过原电脑 TLS 证书验证后同步，无需为换网络重新生成配对码。
5. 分别切换手机到蜂窝网络、电脑到另一网络，验证拉取与手机任务回传。当前版本尚无这项实测结果。

普通局域网地址（例如 192.168.x.x / 10.x.x.x）本身不能实现跨互联网连接；没有提供公共云中继。
无需在路由器把同步端口直接暴露到公网。
