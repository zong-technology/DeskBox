# DeskBox V5 · 分阶段开发

| 阶段 | 实现顺序 | 进入下一里程碑的证据 |
| --- | --- | --- |
| P0.1 基线与工作区 | 核对 main、最新开发分支、历史制作物和外部条件。接入稳定项目上下文和一级导航。改造驾驶舱及既有任务、现场、验证与检索入口。 | 旧数据保留。A/B 项目切换、重名、嵌套目录、重启和键盘导航有回归。 |
| P0.2 AI、MCP、PLC | 项目级会话、授权撤销、离线降级、真实工具状态。补全 MCP 管理、错误、日志、可恢复作业与 PLC 只读验收。 | 模型与 MCP 故障可区分。授权 V20 工程验证发现、读取、诊断及隔离副本回执。 |
| P0.3 稳定性与发布 | 核验 Windows 测试矩阵、项目升级兼容性、备份、恢复、回滚及桌面异常退出。 | 1366×768 至 4K 和 Windows 100% 至 200% DPI。安装、升级、回退与数据恢复有原始日志。 |
| P1 工程流程 | 统一 Tag、资产、工程文档和证据标识。实现 Excel 字段映射及版本差异、DeltaV FHX、验证追踪、工程截图、事故案例、PI 批读和日报周报。 | 场景 C–G 按授权导出物或人工可复现材料执行，报告关联原文和证据。 |
| P2 自动化与移动 | 可视化流程编辑、触发器、版本和故障恢复。进一步完善 iPhone、本地协作、多屏、窗口布局、SQLite 迁移与更新。 | Windows、签名 iPhone 真机、升级/冲突/重连/回滚证据完整。 |

V5.0 发布门槛使用上述场景、功能矩阵及原始测试产物。应用日志与 TIA 运行回执用于工程诊断。正式验证系统的授权、电子签核和审计追踪需另行确认。
