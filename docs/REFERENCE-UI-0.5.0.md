# 0.5.0：12页原生参考布局

本批直接改造现有Windows软件，复用真实服务，不另做网页演示。参考图为 `assets/ui-reference-12-pages.png`。

## 页面与入口

1. 智能桌面：首页工厂背景、快捷入口、最近文件、当前项目进度及目录入口。
2. 工程项目：项目图片卡片、搜索、类型筛选、新建目录关联、查看详情。
3. 项目详情：项目上下文、总进度/N/A、文件页签、项目内搜索、既有27节点验证进度编辑。
4. 工程工具：12张工具卡片；外部TIA/WinCC/DeltaV/Kepware等首次选择本机EXE/快捷方式，保存后可直接启动。
5. 仪表计算：4–20mA双向换算、滑块、百分比与越界状态；拒绝NaN/无穷大输入。
6. AI&SI：实际服务商切换、消息区、输入和真实工具执行状态；会话及参数可展开。
7. 自动化：左侧工作流、右侧节点预览、预演与确认执行；高级新建和编辑保留。
8. 文件搜索：实际索引、筛选、项目范围；顶栏回车直接进入检索。
9. 任务与提醒：四个实际状态指标、任务表格、完成/编辑/提醒等原有功能。
10. 现场事件：实际事件、状态筛选、搜索、调查及处理编辑，沿用版本保护。
11. 天气：城市实况、逐小时曲线、未来预报，缓存与失败状态明确显示；城市搜索保留。
12. 移动同步：LAN和CLOUD分别展示、设备列表、账号设置、真实云登录网址二维码。

项目详情由项目卡片进入，计算器由工具矩阵进入；12个页面共享侧栏、顶栏和状态栏。其他既有功能在“更多功能/设置”，经典工作台和原来的主页模式继续保留。

## 数据与操作

- 不将参考图中的示例项目、文件、天气、在线状态复制为生产数据。
- 旧项目、任务、AI对话、文件授权、云凭证与同步服务沿用。
- 第一次升级启用参考布局；可点击左侧“经典工作台”回退，在设置→外观勾选“使用12页参考图工作台”切回。
- 主题切换沿用已有设置；输入和聊天消息不因切换主题被重建清空。
- QR使用本机Python的qrcode组件生成，只编码云登录网址。组件未就绪时保留复制网址入口，不展示虚构二维码；文档组件安装脚本已包含该依赖。
- Windows版本更新为0.5.0。本批不改变云端协议，不需要重新配对或更新iOS安装包。
