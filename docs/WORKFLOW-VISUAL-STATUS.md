# 自动化页节点可视化

- 选择工作流显示实际节点顺序；旧工作流显示触发器、条件、动作链。
- 状态来自最近一次运行的 NodeRecords，区分预演通过、实际成功、失败、跳过、无记录。
- 点击节点只打开只读详情，不执行动作；显示节点参数、输入/输出、耗时和错误。
- 复制、启停、运行和预演后保留所选工作流；详情与选择同步。
- 流程较长时水平滚动；参数工具条可滚动，避免小屏裁切。
- 本批不是拖拽式节点编辑器，也不伪造运行中节点的实时状态。
