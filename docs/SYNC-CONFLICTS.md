# 手机同步冲突处理

电脑进入“手机联动”→“处理同步冲突”。左侧选中记录后，中间显示当前电脑数据，右侧显示设备提交版本。
比较字段、版本和删除标记，再选择“保留电脑版本”或“采用设备版本”。确认后才应用。

- 保留电脑版本以当前最新数据为准，不会回退到冲突刚产生时的旧快照。
- 比较后发生新修改时，版本保护会拒绝旧选择；点击“刷新差异”重新比较。
- 采用设备数据会回写实际任务或已有项目配置；选择删除标记会移除相应配置，不删除磁盘文件夹。
- 记录 ID 与正文 ID 不匹配时拒绝应用，不会写到别的任务或项目。
- 选择结果生成新版本并进入同步队列；设备再次发送已经处理过的同一旧提交时，服务返回 Resolved，避免反复制造同一冲突。
- iOS 源码已增加 Resolved 确认处理；需要使用更新后的手机源码构建，旧客户端不一定能正确结束重试。
- 同版本但正文不同的新修改仍会形成新冲突，不能当作旧提交丢弃。

Windows 专项14项通过；包含真实任务回写、版本、队列、删除、重载持久化和界面内容检查。完整回归33个套件、522项通过后，追加了两项电脑删除场景检查并通过。
本次启动已发布过的电脑任务被删除后会产生删除标记；未观察到的离线数据变化仍需后续持久删除日志完善，不会把所有缺失记录自动当作删除。
