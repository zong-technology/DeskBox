# DeltaV FHX 离线兼容矩阵

本版基于流式词法读取嵌套花括号结构，并记录对象原文跨度。赋值、引号、分隔符、块与行注释由解析器处理。报告同时保留原始对象类型、字段、未分类对象和诊断。业务结构按导出文本明确提供的信息提取。

| 输入或对象 | 当前状态 | 证据或限制 |
| --- | --- | --- |
| UTF‑8 有／无 BOM，UTF‑16 LE/BE 有 BOM | 支持 | 带哈希、严格解码及原文定位；Windows 和 Linux 使用离线格式夹具。 |
| 无 BOM UTF‑16、GB18030、Windows‑1252 | 有条件支持 | 无 BOM 的 UTF‑16 可依据明显字节特征识别。GB18030、Windows‑1252 可由用户选择。不能解码时显示错误，需要按原编码重读。 |
| Area、Module、Module Definition、Module Class、Unit Class | 结构化 | 从支持的对象头、字段及块关系提取。保留原对象名、层级、位置。 |
| Parameter / Attribute Instance / Attribute Definition | 结构化 | 提取对象字段。VALUE 等子块可在对象列表查看。参数语义、类型枚举换算与单位映射由原数据确认。 |
| Alarm、Phase / Phase Class、Recipe / Control Recipe | 部分支持 | 识别对象头与字段；厂商内部执行语义、报警策略、批次步骤和跨对象引用未验证。 |
| Tag 与带可识别身份的参数 | 可导入统一 Tag | 需要可定位名称及系统。说明见使用指南。 |
| 厂商扩展类型、未知字段及顶层语句 | 保留 | 显示未识别和定位，比较报告提示未识别项。名称重复或语法不闭合时，不产出比较结论。 |
| 无结构、无有效编码、重复身份、未闭合引号或花括号 | 诊断或阻塞 | 保留已识别记录及问题位置，严重错误阻止导入和差异结论。 |
| DeltaV 版本或导出工具标识 | 待真实样本 | 当前没有获得按发行版本标注、经授权的客户或厂商生产工程导出。各 DeltaV 发行版本都留作独立验收。 |
| 在线 DCS、二进制数据库或工程包 | 未接入 | 本轮处理本地 FHX 文本和工程表。 |

解析最大 128 MiB 源文件、50000 个结构记录及受限字段内存。按流分批解码、可取消。小文件结果按项目和 SHA‑256 缓存在当前进程，换项目与改变源文件不会命中原缓存。报告只对所选离线文件有效。运行版本、平台、导出步骤和样本授权状态应在真实样本验收报告中单独记录。
