# DeskBox V5 · 技术债

| 优先级 | 发现 | 整改与复核 |
| --- | --- | --- |
| P0 | main 快照和 Windows 工程分支分离，直接重建 main 会遗漏后续功能 | 从 `1930b40` 进行增量修改。保留提交、编译、发布与安装证据链。 |
| P0 | 项目选中状态只覆盖部分视图。历史任务使用项目名称时存在重名歧义。 | 用稳定 ID 绑定。只有唯一匹配的历史名称参与项目范围，重名或未绑定记录保留供全局管理。 |
| P0 | 资料路径、全局文件索引、AI 临时授权、工作台草稿各自定义范围 | 共享项目快照和路径校验。项目转换撤销会话授权，重置旧项目视图并保留项目各自的磁盘记录。 |
| P0 | AI 可从全局权限与应用工具读取多项目数据。旧会话重载时无项目信息。 | 项目级外部模型开关默认关闭。会话按项目分组，工具基于提交时的项目范围。全局历史保留。 |
| P0 | `Json.Save` 先删除旧文件再改名，周期内可能丢失数据且调用方无法确认保存成功 | 对关键新写入使用同目录临时文件与原子替换，向交互层报告失败。验证损坏输入与上一个可用值。逐步覆盖其他存储。 |
| P0 | TIA 作业 MCP 能力偏内部，连接状态与运行结果容易混淆 | 从同一工具注册定义展示能力，报告实际协商及作业回执。V20 许可、版本和工程授权仍单独检查。 |
| P0 | Windows 用户数据与原生 UI 验收依赖隔离环境 | 复用现有 Inno Setup 和 Windows GitHub Actions。Linux 交叉编译、Windows 执行、持证 Siemens 与真实 iPhone 的结果分别记录。 |
| P1 | WinForms 同时维护两个 shell 和多套横向布局 | 保留 .NET Framework 4.8 和经典入口，优先收敛导航、Palette/DesignTokens 和共享控件，再根据工程电脑与插件兼容性评估现代 .NET 或 WPF。 |
| P1 | 多个页面同步读取文件、日志和索引。重建与跟踪依赖内存快照。 | 先测启动时间、搜索、长会话和大目录。以实测安排后台任务、取消、分页及资源释放。 |
| P1 | 验证、事件、同步与附件各有数据格式，缺统一实体和证据链 | 先定义键与项目关联，再在复制数据上验证事务、迁移回滚及版本校验。 |
| P2 | JSON、JSONL 和云 SQL 并行，商用部署涉及兼容性与脱机要求 | 保留现有数据格式。SQLite 迁移前需要数据目录副本、版本映射、双读复核和回滚演练。 |
