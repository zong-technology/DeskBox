# DeskBox V4.2 · 博图 AI 工程师

Windows 测试版 `4.2.0-tia.3` 已发布。先从托盘退出旧版，再安装到原目录保留数据。[Windows 安装包](https://github.com/zong-technology/DeskBox/releases/tag/v4.2.0-tia.3)

在左侧打开「博图 AI 工程师」。默认只读。可从文件中心选中 `.xml`、`.scl`、`.udt`、`.db` 或 `.csv` 后点击「在博图工作台分析」，也可从工作台一次选择多个导出文件。打开程序块查看来源、接口和项目交叉引用候选。LAD/FBD 展示 SimaticML 中可读取的网络部件、符号、块调用和连线端点，图形连线和执行条件需对照 TIA 原工程复核。只读分析也可以调用已配置模型解释所选对象，网络环境会先确认向服务商发送资料。

选择「辅助设计」可生成结构化计划、SCL 草稿和测试用例，或使用确定性的「缩放模板」。草稿编辑器支持关键词高亮、静态检查和另存源文件。静态结果附行号，编译状态单独记录。IO CSV 最少含 `name`，可附 `address,type,device,order,signal`。`signal` 取 `DI`、`DO`、`AI`、`AO`。地址建议按用户填写的 I/Q 起始字节及已填地址避让，需按 CPU、现场模块和槽位复核。设备订货号未知时显示待确认。工程对比可将当前资料设为基线，再选择另一批导出文件或另一个独立 V20 工程。报告的缺口、冲突及证据均保留来源。

V20 原生功能需 Windows x64、实际同版本 Siemens Openness 程序集和当前用户组权限。先关闭或另存源工程，再选择目录中的 `.ap20`。工作台复制完整工程目录，将原始快照、源文件指纹、操作批准、专用工作副本、诊断和差异保留在 DeskBox 数据目录的 `tia-jobs`。用户可将 `snapshot` 复制到新的工程目录恢复。每次新作业使用新副本，源工程变化时要求重新读取和审批。手动选择唯一目标 PLC 后才能编译。批准新增模板需切换「自动离线工程」，确认块名和源文件哈希。保存前比较已读对象的指纹，确认目标 PLC 只增加获批的 FB。取消后核查作业回执和副本状态再重试。

在工作台勾选「授权桌面 AI 查阅已加载工程」后，桌面文字 AI 和全息可调用 `tia.read` 查阅已加载资料。模型可要求查看概况或按唯一名称定位对象，返回来源和受限正文。重新加载资料或切换 AI 环境后需重新授权。操作审计写入「工作记录」，可把诊断摘要添加为当前 DeskBox 项目的待办。
