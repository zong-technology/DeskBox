## 当前升级方式

Windows 使用 `dist/field-0.4.0/DeskBox.exe`，退出旧程序后在原数据配置下升级，保留原证书。
手机使用 `dist/ios/DeskBoxMobile-0.4.0-unsigned.ipa`，由用户按原签名配置覆盖安装。
详细流程见 `手机配对与同步说明.md`。安装包以 `IOS-UNSIGNED-IPA.md` 最新验证记录为准。
