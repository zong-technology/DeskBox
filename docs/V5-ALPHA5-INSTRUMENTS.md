# DeskBox 5.0.0-alpha.5 仪表资产首批增量

## 操作流程

1. 在项目中心选定当前工程。从「现场工程 → 仪表资产」或「工程上下文 → 仪表资产」打开台账。也可在统一工程 Tag 中选中一条记录，打开「关联仪表」，查看该 Tag 的仪表。
2. 新建资产，填写编号、名称、类型及适用的厂商、型号、序列号、位置、信号、工程单位、量程。用项目内的稳定 Tag ID 建立关联，可留空待补。保存后保留历史版本。
3. 通过「设置手册附件」登记项目内原件。替换手册引用时保留旧版档案，原始文件保持原样。
4. 选择仪表，追加校准或维护，填写实际日期和记录。校准可选填证书编号和下一次到期日。附件可引用工程原件或选用验证中心已归档的证据。
5. 选择记录并核验附件。工程目录原件会对比登记时的 SHA-256，匹配时在资源管理器定位。归档证据核验验证中心保留的原始字节。原件引用以项目相对路径与 SHA-256 追溯迁移、缺失或内容变化。需要保留归档字节时先在验证中心归档，再选择证据。
6. 使用「只看到期或逾期」查看逾期、今日到期及未来 30 天的资产。状态以本机日期和该仪表最近一次实际校准的到期日计算。没有登记到期日时显示「未设到期日」。导出当前项目的仪表及校准、维护记录为 CSV 或 XLSX，包含资产 ID、Tag ID、记录 ID、证书、来源、哈希及归档证据 ID。

## 数据与恢复

使用独立的 `instruments/` 项目台账，Version 1、SHA-256 校验、原子替换与上一版备份。修订号与修订令牌一起校验，恢复后即使再次出现同一修订号，旧表单的保存仍会被拒绝。主台账损坏时显示上一版只读数据，确认后可恢复并保留损坏文件。应用备份包含本地仪表台账与已归档证据，项目原件引用所指向的文件按项目资料流程保护。

校准证书和维护记录由操作人员录入。仪表审批及与验证偏差或现场事件的直接关联属于后续增量。

## alpha.5.1 校准到期提醒

1. 保持「功能与设置 → 通知 → 启用应用内提醒」和「当前项目的仪表校准提醒」开启。选择工程后，DeskBox 在运行期间检查每台仪表最新实际校准记录的到期日。
2. 「工程驾驶舱 → 通知」显示当前项目的校准汇总和未读数量。选中「仪表校准提醒」，按 Enter 或点击「查看校准到期」，会打开同一项目的仪表台账并启用到期筛选。汇总分别列出逾期、今日到期和未来 30 天的数量。
3. 同一到期状态只提醒一次。状态变化时更新汇总。清理已读后，相同状态会保持隐藏，即使重启应用。重新校准后，已不在到期范围内的仪表从汇总移除。未设置实际到期日的仪表继续在完整台账中显示。

提醒状态单独保存在本地 `calibration-notifications.json`，既有任务和自动化通知使用原有记录。关闭开关会停止新的校准检查。提醒随 DeskBox 进程运行，通过现有可选的系统托盘提示呈现。在仪表台账的只读备份视图中暂停更新提醒，恢复台账后继续检查。
