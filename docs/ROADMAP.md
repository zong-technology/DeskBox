# DeskBox 开发路线

当前开发与验收基线见[项目状态](PROJECT_STATE.md)，各版本范围、顺序与验收条件以 [V5 开发路线](V5-DEVELOPMENT-ROADMAP.md)为详细记录。更早的规划随历史文档保留。

| 阶段 | 范围 |
| --- | --- |
| alpha.5 | 仪表资产及统一 Tag、校验证书和现场证据。随后推进授权通信资料、PI/UFL、工程知识检索、截图和工作记录。 |
| alpha.6 | 自动化引擎、项目工作空间和移动协同。以真实数据同步、冲突处理和设备测试为验收依据。 |
| beta.1 | 功能及接口冻结，累积回归、性能和恢复验收，核对 UI 交接。 |
| beta.2 | 保持核心服务接口，集中重构 UI 与交互，复测各分辨率、DPI 和高频操作。 |
| RC 至 V5.0 | 联合验收，覆盖实际运行、升级、回退、发布产物校验及适用工业环境。 |

涉及路线、接口或存储的重大调整，应同时更新[决策](DECISIONS.md)和受影响的项目状态及验收记录。
