# DeskBox 5.0.0-alpha.3 工程资料与统一 Tag

## 使用入口

| 入口 | 操作 |
| --- | --- |
| 项目中心 → 工程上下文 → 统一工程 Tag | 查询和按系统筛选，按列排序，翻页，新增、编辑、查询来源及比较历史版本。经典项目中心也有入口。 |
| PLC Studio → 变量管理 → 统一 Tag 与比较 | 打开工程内的 SCL、UDT、DB、SimaticML XML、CAx AML、IO CSV/XLSX 或已导出的 TIA 诊断 JSON。单个已加载离线文件可直接带入。 |
| DCS Studio → 解析与比较 | 将选中或打开的离线 FHX 解析为对象及字段。原有文件列表、原文预览和软件启动入口继续可用。 |
| AI 工程中心 → MCP 管理 → 第三方 MCP | 发现真实工具，核对 Schema 与资料范围。选择「允许 AI 申请」授予当前项目内本机只读服务的工具资格。 |
| AI 工程中心 → 工程会话 | 授权或附加项目内文件，要求比较资料或查询 Tag。关注工具结果中的文件名、SHA‑256 和位置。 |

## 导入、比较与导出

1. 选择项目，打开「工程资料与差异」并选择项目根目录内的导出物。XLSX 默认读第一张工作表，也可输入指定工作表名。FHX 与 CSV 会检测 BOM 和 UTF‑16 字节特征，默认使用严格 UTF‑8，也可显式选择兼容编码。
2. 在「默认系统」填实际系统 ID，或由输入中的 SystemId 列提供。选择「映射并预览 Tag」，确认表格列映射和导入预览。缺少 TagName/SystemId、同系统重复、无效数值或量程矛盾会阻止导入。自定义数据类型、已有单位不一致和缺失可选字段会提示核对。
3. 「导入／补充来源」新增 Tag 并给匹配项附上本次来源，保留已有字段。「确认更新映射字段」按本次映射更新匹配项，空映射单元格可以清空对应字段。两种操作均需明确确认，台账或文件变化后应重新预览。
4. TagId 固定用于关联与历史，匹配导入使用项目内 SystemId 与 TagName 的组合。相同位号可在不同项目或系统中使用。PLC XML、FHX 和 IO List 使用相同的系统与 Tag 名后，来源会关联至同一 Tag。FHX 只收录明确的 Tag、带 TAG_NAME 的参数，或能定位到具有类型字段的命名参数；后者使用父对象名加参数名表示引用。
5. 「与另一版本比较」使用确定性对象键和字段生成新增、删除、修改及诊断。CSV、TSV 和 XLSX 可跨表格式比较。选择「导出差异 JSON」保存文件名、哈希、原文位置和明细，主条目及省略计数随报告保存。SCL 导出比较基于已有块解析和内容指纹，不编译或执行程序。
6. 从 Tag 台账导出完整项目 CSV 或 XLSX。源文件和已存在的输出文件保留。XLSX 只读静态值，含公式的输入需另存为值。CSV 输出对类似公式的非数值文本添加字面量前缀，XLSX 用文本单元格保存。

Tag 台账按项目单独写入现有数据目录的 `engineering-tags/`。快照采用原子替换、内容 SHA‑256、上一版备份和并发标记。主文件损坏时只读上一份备份，确认「恢复台账」后保留损坏原件并恢复可写状态。既有项目、会话和 TIA 作业文件仍沿用原有位置。

## AI 和 MCP 权限

桌面 Agent 可调度 `engineering.compare` 和 `engineering.tags`。文件工具受当前项目、受信目录或附件与 AI 文件权限控制。第三方 Agent 调用当前限定为同项目已授权的数值回环 HTTP、数值回环模型、声明只读及封闭范围且输入 Schema 可验证的服务。每次调用均检查参数、请求人工确认、重新协商和核对授权指纹。授权撤销、参数无效、Schema 漂移、断线及取消会留有状态。Agent 步骤记录关联实际 MCP 回执 ID。旧手动 HTTP＋Bearer 与 stdio 入口保留，OAuth 尚未接入。
