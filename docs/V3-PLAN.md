# DeskBox v3 · 审查结果与升级计划

> 依据《DeskBox 桌面工作台：完整产品规格书与现有项目升级任务书》逐条比对现有代码后制定。
> 原则：不推翻现有实现、保留可用功能与用户数据、先修问题再补功能、所有功能真实可用。

## 一、现有项目审查结果

| 检查项 | 现状 |
|---|---|
| 技术栈 | C# WinForms / .NET Framework 4.8，`csc.exe` 编译，零第三方库，单文件 EXE（约 296 KB） |
| 构建 | `build.ps1`（csc 直接调用）→ `dist\DeskBox.exe`；`install.ps1` 安装到 `D:\DeskBox` |
| 运行形态 | 无边框全屏置底窗口（不抢焦点），可接管系统桌面图标；托盘控制 |
| 数据存储 | `D:\DeskBox\data\`：`state.json` / `tasks.json` / `logs.jsonl` / `history.jsonl` / `index.json` / `cache/weather.json` / `undo.json` / `workflows.json` |
| 已实现且可用 | 桌面分类整理、隐藏/显示、三视图、时钟、任务（增删改/优先级/截止/筛选）、日志、天气（Open-Meteo）、系统监控、磁盘分析、文件搜索（60477 条实测）、收藏/标签、批量重命名+撤销、文件预览、AI 本地助手、自动化工作流（基础）、剪贴板历史、主题 |
| 缺失/不足 | **AI 无对话与多服务商**、**API Key 明文存文件**、**无启动动画**、**天气无城市管理（仅文本城市名）**、**任务无提醒**、**无统一工作记录页**、**设置页分散**、**数据目录依赖 EXE 所在目录可写**、导航命名与规格不一致 |

## 二、差距清单（对照规格）

| 规格条目 | 现状 | 处理 |
|---|---|---|
| 4.1 AI 服务商管理（增删改、默认、模型、超时、重试、启用） | 无（仅单一 endpoint/key/model） | 新增 `ProviderStore` + 服务商管理页 |
| 4.2 API 兼容性（OpenAI Chat Completions 等） | 单一实现、无协议区分 | 抽象 `IAiClient`，OpenAI 兼容 + 自定义鉴权头 |
| 4.2.5–4.2.9 密钥安全 | 明文 JSON | 改用 DPAPI（`ProtectedData`，当前用户作用域）+ 脱敏日志 |
| 4.3 连接测试（区分 9 类错误） | 无 | 新增 `TestConnection` 返回分类结果 |
| 4.4 AI 对话（多轮、流式、取消、重生成、复制、Markdown、历史） | 无 | 新增 WorkBuddy 页 + `ChatService` |
| 4.5 AI 工具调用（受控、授权、确认） | 无 | 新增 `ToolRegistry`（白名单 + 风险分级 + 授权目录） |
| 5.x 工作流（节点/数据传递/取消/AI 节点） | 单动作、无数据传递、不可取消 | 升级为节点流水线 |
| 6.1 天气城市管理（搜索/常用/切换/唯一标识） | 仅城市名文本 | 新增城市搜索（geocoding）+ 常用城市 + 坐标存储 |
| 8 任务提醒 | 无提醒 | 新增提醒时间 + 应用内通知 |
| 10 工作记录 | 仅文件操作历史 | 新增统一记录（AI/自动化/文件/任务/配置/错误） |
| 11 设置中心 | 单体设置窗体 | 分页设置中心，全部真实生效 |
| 12.1 数据目录 | EXE 同级 `data` | 迁移到 `%LOCALAPPDATA%\DeskBox\data`（若 exe 目录不可写则自动回退），保留旧数据迁移 |
| 3.3 启动动画 | 无 | 新增 Splash（真实初始化步骤，非阻塞、非假进度） |

## 三、实施顺序

**P0（本次优先，AI 核心）**
1. `CoreSafe/DataPaths`：数据目录解析 + 旧数据迁移（原子、可回滚）
2. `Ai/ProviderStore`：多服务商 CRUD、默认服务商/模型、DPAPI 加密 Key、脱敏日志
3. `Ai/AiClient`：OpenAI 兼容 Chat Completions（含 SSE 流式）、超时、重试、错误分类
4. `Ai/ChatService`：会话持久化、多轮上下文、流式回调、取消、重生成
5. `UI/Views/ChatView`（WorkBuddy）：会话列表、气泡渲染、Markdown 轻量渲染、停止/重生成/复制、服务商切换
6. `Ai/ToolRegistry`：白名单工具（搜索/读取/摘要/建任务/存文件/整理建议/报告/触发工作流）+ 授权目录 + 高危确认

**P1**
7. 启动动画（真实初始化：加载配置 → 初始化服务 → 建索引 → 进入主界面）
8. 天气城市管理（搜索/常用/切换/逐小时）
9. 任务提醒 + 应用内通知
10. 工作记录页（统一 AI/自动化/文件/任务/配置/错误）
11. 设置中心分页（外观/AI/天气/自动化/文件与隐私/通知/系统）

**P2**
12. 工作流 v2：节点流水线（触发/条件/AI/操作）、数据传递、取消、复制/启停
13. 导航命名对齐规格（首页 / WorkBuddy AI / 自动化 / 文件管理 / 任务与提醒 / 天气 / 系统监控 / 工作记录 / 设置）

## 四、验收方式

- 每个模块独立测试：真实文件、真实 HTTP（可用本地 mock 服务验证错误分支）、真实系统接口。
- 最终执行规格书第十五章 A–G 清单，逐项标注通过/未通过，未通过的写入"已知问题"。
- 交付：源码 + 新版 EXE + 构建说明 + 功能清单 + 测试结果 + 已知问题 + 配置说明。
