# alpha.4 验证统计口径

验证统计从当前项目的台账快照、有效追踪关系及适用筛选计算。现有 ValidationProgress 单独展示阶段计划进度，需求、测试、审核、偏差与交付各按实际记录计算。筛选阶段、系统、设备、风险等级及 Tag 时，可从需求、测试和关联资料读取匹配项。项目及实体以稳定 ID 去重。

| 指标 | 分子或记录数 | 分母及排除规则 |
| --- | --- | --- |
| 适用需求总数 | 适用、未作废且有效的当前需求数 | 计数。排除撤回、已作废、被替代和不适用的需求。 |
| 已关联有效测试的需求数 | 至少经直接或下游追踪关联到一项适用测试的适用需求数 | 计数。一个需求多项测试仍记为一条。 |
| 需求覆盖率 | 已关联有效测试的需求数 | 适用需求总数。覆盖表达关联关系，执行结果和证据另列。 |
| 测试用例总数 | 筛选范围内的当前、有效、适用测试用例 | 计数。排除撤回、已作废、被替代和不适用的用例。 |
| 已执行测试数 | 当前用例修订的最新未撤回执行记录为通过、失败或阻塞的用例数 | 计数。同一用例的历史执行不重复贡献。 |
| 测试执行率 | 已执行测试数 | 当前、有效且适用的测试用例总数。 |
| 测试通过率 | 当前用例修订的最新未撤回执行为通过的用例数 | 当前状态为通过或失败的用例数。阻塞、执行中、不适用和尚未执行不计入。 |
| 待审核记录数 | 有效审核对象中缺少当版人工批准或驳回记录的数量 | 计数。包括适用需求、用例、终态执行及筛选范围内的相关设计、风险、证据、偏差、CAPA、Punch、文件和影响记录。 |
| 审核完成率 | 当前修订有人工批准或驳回的审核对象数。关闭偏差携带明确的前版批准依据 | 应审核记录总数。批准和驳回均计为有决定，结果可单独查看。 |
| 开放偏差数 | 未关闭且未撤回的偏差数 | 计数。使用筛选范围和关联执行。 |
| 偏差关闭率 | 已关闭的偏差数 | 筛选范围和关联执行下的全部未撤回偏差。 |
| 缺失证据数量 | 当前终态执行中缺少证据的执行记录数 | 计数，按执行 ID 去重。传入证据验证服务时，至少一份关联证据须通过校验。仅检查关联时，结果注明归档文件未校验。 |
| 待评估变更数量 | 状态为草稿或待评估的有效变更影响记录数 | 计数，遵守当前筛选。 |
| 交付资料完整率 | 已确认完成、备妥或交付，且有有效项目文档引用和来源哈希的必需交付项数 | 当前有效且必需的交付项总数。文件级完整性可通过证据校验单独核对。 |

比率的分母为零时返回空值，界面显示「不适用」或「无数据」。测试的当前状态以执行时间、创建时间和稳定 ID 决定排序，修订用例后可从历史回查原执行。重测由新增执行记录表达。RTM 汇总同一用例及其各次执行的偏差，重测通过后原执行的开放偏差继续可见。历史执行计数可包含既有修订和撤回记录，独立于当前统计。

RTM 的无来源用例指缺少来自适用需求的追踪路径。记录文件及位置是单独的来源字段，手工记录可保留人工来源。
