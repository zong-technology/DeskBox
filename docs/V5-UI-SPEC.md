# DeskBox V5 第一阶段 · 工作台界面规范

## 导航与信息层级

顶部顺序为主导航开关、DeskBox 标识、当前工程、工作模式、工程文件搜索、命令和工具抽屉。空间不足时，保留项目、模式、命令、工具及导航开关。搜索仍可从知识库或快捷键进入。

一级导轨共 12 个模块，默认图标宽度 62 设计像素，展开宽度 194。按钮保留完整可访问名称，支持 Tab、Enter，工具抽屉保留传统全局功能和经典界面。项目详情、任务和上下文在项目中心的二级导航，计算和工具矩阵位于现场工程，MCP 位于 AI 工程中心。

驾驶舱的顺序是项目进度和工作建议，临近任务和问题，变更文件和近期工作。每个区域以真实数据支持操作，按 Enter 进入对应资料或模块。根目录失效、无数据及无模型均提供可区分的文本状态。

## 设计变量与自适应

新控制沿用 `src/UI/Palette.cs`、`DesignTokens.cs`、`UiKit.cs`，使用现有主题和用户强调色。共享控件通过统一调色板应用背景、文本、边框、悬停与焦点。采用 Microsoft YaHei UI，保留中文可读性。顶栏和导航使用系统 DPI 换算，分区内容按可用宽度分配，长文本使用省略和悬停提示。

工程设计、现场调试、验证测试和项目管理四个工作模式保存在用户设置，选择模式打开对应主工作区。PLC Studio 的既有可拖拽分栏、展开与折叠继续使用。其他页面的统一停靠、多标签、多屏布局保存与恢复列入后续阶段。

真实 Windows 运行尺寸、DPI、截图、手工目视结论与未覆盖项另见验收报告。
