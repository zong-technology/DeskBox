## Windows 安装与回归

GitHub Actions 的 Windows Server 2025 Datacenter build 26100 完成原生构建、Inno Setup 打包和验收。

- 安装、启动、升级、重装、回滚与卸载通过 **85 项**。用不同字节的旧程序夹具演练回退。安装后运行的二进制与构建文件 SHA-256 一致，升级、回退与卸载保留测试数据。
- 全息语音的 **138 项**原生回归运行于同一个经 SHA-256 核验的 Windows 二进制，使用本机测试传输和音频夹具。真实装机 TIA 输入另行验证了 96、120、144 DPI 下的物理点击、英文输入、换行和中文剪贴板输入。
- TIA 离线回归通过 186 项、AI 环境通过 22 项、AI 应用操作通过 14 项。移动 AI 通过 13 项，移动任务与同步冲突步骤也通过。测试机无持证 TIA，不具备 Siemens 真实工程读写与实际编译回执。
- 旧式测试宿主曾在安装步骤重复运行时挂起。当前 CI 对其首次真实执行记录绑定二进制 SHA-256，在已安装字节独立校验后复用该记录。安装程序启动、输入、数据保留和回滚仍由安装测试实际运行。
