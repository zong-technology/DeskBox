# UI 与功能交接验收

- 普通工程会话能发送、输出流式内容、停止，并查看每轮任务的真实结束状态。用户切换项目后，会话、附件、检索和运行记录同步切换。使用原项目可查看被取消回复及其回执。
- 没有可用模型时，可输入真实文件名关键词，查看当前范围内的索引源路径和结果为空的情况。至少一种工程计算在无模型依赖时立即产生实算结果。
- 在设置选择实际服务商运行文本流探针，能分辨收到文本增量、收到结束帧、超时、认证和协议提示。
- MCP 新注册实际写入，默认停用。启用的真实服务可进行版本协商、工具发现、Schema 展示和检测结果查看。
- 未授权、拒绝本次执行和目录变化时，测试服务器未收到 `tools/call`。已授权运行有实际结果与回执。取消、失连、超时与权限拒绝在历史中可区分。
- 正常操作及错误无控件遮挡。长步骤及 Schema 区域可滚动，表单可用键盘提交。实际 Windows 运行时测试主要入口，截图记录显示尺寸、DPI、源码与构建身份。
- 原始版本可使用既有会话／项目文件。升级保留数据。原生 Windows、回环协议、官方 SDK 互操作、真实工程验证分别记录。

## alpha.3 验收

- PLC XML、DeltaV FHX 和 IO List 共享一个工程 Tag 的稳定 ID 与来源，系统和 A/B 项目可同时有同名 Tag。
- FHX 能浏览嵌套对象、定位原文并比较两个版本。未知对象与语法错误有真实诊断。
- XLSX/CSV 导入预览后须明确确认，能够导出并重新读取。并发、取消、源修改和磁盘故障保留旧台账。
- 可向模型给出工程对比需求，结果引用本地真实差异；第三方 MCP 的无权限、撤销、漂移和断流均被约束。
- 可在 Windows 从三处实际入口打开资料，查看反馈及截图。物理设备和厂商版本验收单独说明。
