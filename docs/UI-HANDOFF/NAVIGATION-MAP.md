# 导航图

| 一级模块 | 当前主要入口 |
| --- | --- |
| 工程驾驶舱 | 项目选择器、任务、问题、进度、最近文件、近期操作。 |
| 智能桌面 | 本机桌面、目录、文件操作。 |
| 项目中心 | 项目目录、项目详情、工程上下文、项目任务。 |
| PLC Studio | TIA 工作台、导出资料、规划、草稿、离线验证和作业。 |
| DCS Studio | 当前工程导出的 FHX、文本等预览。 |
| 验证中心 | 验证阶段、加权进度、模板、资料路径。 |
| 现场工程 | 现场事件、工程工具、信号换算、计算与诊断。 |
| AI 工程中心 | 工程会话 → 执行记录。MCP 管理 → 本机探测／第三方 MCP → 注册编辑／工具发现／调用记录。 |
| 工程知识库 | 工程资料、收藏和标签、文件操作历史。 |
| 自动化中心 | 工作流管理、运行和历史。 |
| 移动协同 | 同步、配对、冲突、移动状态。 |
| 系统设置 | AI 服务商与能力探测、外观和系统选项、数据备份、设备设置。 |

工程数据页共享顶部项目选择器。经典工作台保留现有导航及工程会话中的执行记录入口。
