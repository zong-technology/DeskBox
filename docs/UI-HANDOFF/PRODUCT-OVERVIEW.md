# DeskBox 产品交接

DeskBox 面向制药设备自动化、PLC、DCS、现场调试与验证工程师。顶部项目选择器决定本轮会话、文件检索、工程作业与事件的范围。未绑定工程是独立范围，保留旧数据和全局工具。

5.0.0-alpha.2 交接内容涵盖桌面文字 Agent、第三方 MCP、本机 TIA MCP 与现有工程导航。第三方 MCP 供操作者按项目注册、发现和人工执行只读工具。Agent 使用 DeskBox 已注册的工具和现有工程权限。项目的外部 AI 权限与 MCP 服务授权分别配置。

现有 WinForms 保留。后续表现层重构可以复用业务入口、业务状态和标识。功能及服务接口在 beta.1 冻结后交给视觉设计阶段。
