# 可复用组件

| 组件 | 数据绑定 | 操作与无障碍需求 |
| --- | --- | --- |
| 项目选择器 | ProjectContext.Id、Name | 保留未绑定入口。切换后更新各模块访问范围，操作中提示取消。 |
| 会话列表与消息区 | ChatSession、ChatMessage | 保持键盘选择、查找、复制、查看工具结果和部分回复。 |
| 编辑框与运行状态 | 消息内容、当前模型、Busy、ActiveTaskId | 保留多行输入、附件、发送、停止。消息过长和权限错误在可读区域展示。 |
| 执行记录表与步骤区 | AgentTask 和 AgentStep | 查看步骤耗时、协议证据与失败，键盘选中任务，区分可停止与已完成。 |
| MCP 服务选择器和注册表单 | McpServer | 展示启停和传输。按传输调整字段，令牌另用密码输入框。 |
| MCP 工具列表、Schema 与参数 | McpCatalog、McpTool | 目录来源、授权状态、输入／输出 Schema 可完整阅读。参数框保留滚动和键盘。 |
| MCP 响应和历史 | McpResult、McpReceipt | 结果可定位至回执 ID。显示代码、发送状态、取消、重新检测入口。外部文本按纯文本展示。 |
| 模型探测状态 | ModelProbe | 分别显示实际文本流、结束帧、响应状态和可用 Tokens。 |

本轮新增原生文本框、按钮和列表作为功能入口。旧桌面、导航和工程工作台布局继续使用仓库既有组件。后续可用统一组件替代这些原生控件，保留动作和业务状态。

## alpha.3 组件

- Tag 涉及项目标头、分页列表、系统过滤、字段编辑、来源清单和版本选择。
- 文件资料区由路径、SHA-256、编码、工作表、对象父路径、来源跨度、可滚动诊断和报告组成。
- 映射预览需支持自动列建议、人工索引选择、行位置、不一致和明确的写入方式。
- MCP 工具需显示人工许可、Agent 可申请、无权限、Schema 更新、取消及回执 ID。
