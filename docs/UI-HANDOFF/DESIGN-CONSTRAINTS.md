# 表现层约束与工程边界

- 当前以可操作、易查错、键盘可达为验收目标。保留现有 WinForms、工作区和工具入口。功能稳定后集中设计视觉、动画、多屏和高级布局。
- 表现层调用应用服务。工程范围、工具授权、调用生命周期和持久化规则由应用服务及数据层执行。
- 窗口缩放后表单输入、执行按钮、错误和取消仍可达。长 Schema、响应及历史应滚动，后台操作通过事件或返回结果更新 UI。
- 会话、任务和 MCP 注册、权限、回执都遵守项目边界。清楚显示当前工程和 AI 环境。AI 环境的本地隔离仅允许数值回环 HTTP，第三方 stdio 禁用。
- MCP Schema 和注解来自服务器。只读标签属于待审核的供应方声明。通用 MCP 无法代替品牌工业环境的只读账号、脱机导出及工程审批。
- 已启用的 stdio 程序运行于当前 Windows 用户权限。参数包含路径时应由有权限的用户显式提供，凭据不得写入可分享配置。HTTP Bearer 从遮挡输入框临时提供。
- 持久化回执展示实际发生的步骤，并区分模型建议、执行结果和工程验证。应用记录用于诊断。正式验证与签核沿用其独立项目流程。
- 既有项目文件和配置继续使用原格式。新元数据增加独立目录。界面不能通过组件改版改变数据范围和业务契约。
