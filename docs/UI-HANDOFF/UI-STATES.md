# 界面状态

| 能力 | 等待／加载 | 空数据 | 成功 | 取消与失败 |
| --- | --- | --- | --- | --- |
| 模型对话 | 准备任务、连接、接收流、等待人工、执行工具 | 新会话可直接输入 | 收到结束帧、任务完成 | 保留已收到文本。工具失败后模型可能完成回答，任务状态为 partial。 |
| 本地搜索或计算 | 查询索引或执行确定性计算 | 权限内没有匹配文件，显示实际索引状态 | 源路径或计算结果 | 取消、中断、参数或文件权限错误。 |
| 模型探测 | 正在发送固定测试内容 | 未设置服务商或地址，提示设置 | 观察到真实 SSE 文本与结束帧 | HTTP、认证、环境、超时或协议错误。 |
| Agent 执行记录 | 异步读取当前工程与 AI 环境 | 当前范围没有运行记录 | 选择并查看步骤。运行中的任务可停止 | 读取错误可刷新。中断显示明确状态，任务可由用户重新发起。 |
| MCP 注册和工具目录 | 保存或发现期间显示执行状态 | 无注册提示新增；服务无工具时显示真实空目录 | 显示协议版本、服务与工具定义 | 失败提示认证、协议、网络等。取消可再次手动检测。 |
| MCP 人工调用 | 等待真实响应，支持取消 | 无授权或无选中工具时不可调用 | 展示真实输出 | 展示执行错误、收发状态和回执。发送后的取消不能确认远端是否执行。 |
| MCP 调用历史 | 读取当前项目及服务记录 | 显示没有调用记录 | 展示真实调用时间、状态和耗时 | 旧的未结记录标为 interrupted；损坏配置从可用备份载入，并停用服务及旧授权。 |

## alpha.3 状态

| 流程 | 空或加载 | 成功／中断／错误 |
| --- | --- | --- |
| 读取 PLC／FHX | 尚未选资料、后台解码与读结构 | 可选定位。未识别对象保留，阻塞诊断明确。取消不分配新资料。 |
| 预览／提交 Tag | 等待工作表、列映射及明确的写入方式 | 显示新增、更新、来源、未改数量。重复或校验失败保留台账。 |
| 版本差异 | 等待两个版本及可选映射 | 差异、两个源哈希和位置。若资料损坏或身份重复则显示诊断。 |
| 备份读取 | 当前项目没有台账或主文件损坏 | 损坏时只读备份，明确提示手动恢复。 |
| Agent 申请 MCP | 可用目录为空、已读取实际 Schema、等待人工 | 已授权并实际发送时有结果或远端状态未知提示，拒绝和撤销均阻止发送。 |

## alpha.4 验证状态

| 区域 | 状态与呈现 |
| --- | --- |
| 总览 | 无数据时显示空指标或不适用。计划进度和实际统计分别显示。 |
| 导入预览 | 显示可提交候选、冲突及阻塞错误。来源修改后要求重新读取。 |
| 执行 | 未执行、执行中、通过、失败、阻塞、不适用、已撤回。显示引用的用例修订和历史执行。 |
| 证据 | 已归档、校验通过、缺失、损坏、读取错误。版本衍生关系单独展示。 |
| 偏差 | 新建、评估、调查、处理、重测、审核、已关闭、已撤回。 |
| 审核 | 独立结论，与被审核记录 ID 与修订一起呈现。 |
| 基线及变更 | 已捕获的版本、候选影响、未匹配差异和待评估。 |

`not-executed` 为投影值，表示当前用例修订缺少适用执行。执行状态保存为 `running`、`passed`、`failed`、`blocked`、`not-applicable` 或 `withdrawn`。偏差状态保存在独立字段。当前修订已有 `approved` 或 `rejected` 人工记录时，业务审核显示对应结果；其他当前修订显示待审。偏差关闭修订保留明确的前版批准依据 ID。
