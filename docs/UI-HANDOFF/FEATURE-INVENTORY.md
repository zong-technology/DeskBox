# 功能清单

| 功能 | 用户输入 | 用户可见结果 | 权限与关联 |
| --- | --- | --- | --- |
| Agent 对话与重生成 | 当前会话的消息、模型、参数、可选附件 | 流式回答、工具结果、失败或取消时保留的部分文本 | 当前项目、AI 环境、服务商启用状态、项目外发开关、附件文件权限。关联会话与任务记录。 |
| 模型探测 | 已保存服务商、协议、地址、模型 | 普通连接状态或实际 SSE 文本和结束帧、HTTP 状态、耗时、可选 Tokens | 设置界面人工触发固定短探针，遵守 AI 环境策略。 |
| 本地项目工具 | 文件名关键词，或工程计算命令及参数 | 本地文件路径、空结果或真实工程换算 | 文件权限及项目范围。无项目时需要授权根目录或单文件。计算只执行确定性工程工具。 |
| Agent 执行记录 | 当前项目、AI 环境、要查看或取消的任务 | 任务状态、步骤、耗时、Tokens、错误类别 | 可停止当前会话服务中匹配的活动任务。会话历史通过 SessionId 关联。 |
| 第三方 MCP 注册 | 名称、传输、端点或可执行文件、启动参数、超时 | 持久化编号、配置版本、启用状态 | 注册固定归属当前项目。新注册停用。stdio 只接受可信程序。 |
| MCP 检测和权限 | 已启用服务、可选 Bearer、从实际目录选择的工具 | 协议版本、服务标识、输入与输出 Schema、提示、保存的授权 | 只读能力由操作者审核。拒绝明确表明写入或破坏的工具。Schema 或身份变化需重新授权。 |
| MCP 人工调用与回执 | 已授权工具、JSON 对象、当次确认 | 实际 JSON 结果或失败、耗时、调用 ID、发送阶段 | 独立项目范围，每次显式确认。回执保存元数据。 |
| 本机 TIA MCP | 策略开关、当前工程、协议测试或授权作业 | 私有进程协商、工具目录和真实作业回执 | 保留 PLC Studio 既有只读权限与离线副本审批。 |

## alpha.3 工程资料

| 功能 | 用户输入 | 输出及关联 |
| --- | --- | --- |
| PLC 资料分析 | 已授权的离线导出、来源版本及诊断 JSON | 程序对象、变量、引用、原始位置和哈希。继承现有 Openness 权限和独立验收。 |
| DeltaV 资料分析 | FHX、可选编码和版本 | 树形身份、字段、原文、未识别内容及解析诊断。可从识别出的 Tag 和参数预览导入。 |
| 统一 Tag | 项目内的手工字段，或 XLSX／CSV／TSV、PLC XML、FHX 与字段映射 | 工程 Tag、稳定 ID、字段差异、来源链接、历史版本和导出。 |
| 工程差异 | 同类资料两版、工作表和列映射 | 新增、删除、修改、原始位置、SHA-256、阻塞诊断及 JSON 报告。 |
| Agent 工具联动 | 当前项目、条件、明确授权的文件或本机 MCP | 工程差异或 Tag 数据。MCP 有实时 Schema、单次审批、实际执行回执和任务关联。 |

## alpha.4 验证功能

| 功能 | 操作者提供 | 服务返回 |
| --- | --- | --- |
| 阶段、验证计划与资料 | 当前项目、范围、阶段、文档编号、版本、来源 | 独立计划和资料记录。原有计划进度仍可查。 |
| 需求与设计 | 人工录入或经确认的提取结果、文档版本、风险、适用性 | 带稳定 ID 和修订历史的需求与设计引用。 |
| 风险及追踪 | 人工评价、控制和剩余风险、关联的记录 ID | 风险记录、双向追踪、覆盖缺口及关联诊断。 |
| 测试方案、用例及执行 | 测试说明、步骤、预期、实际结果、执行人员、重测前次 ID | 设计和执行分别保存。原执行可查当时的用例与步骤。 |
| 证据、问题及人工审核 | 原始文件、衍生件、执行或需求 ID、调查、审核决定 | 文件归档、完整性结果、历史、偏差、CAPA 及 Punch List。 |
| 变更影响与基线 | 两版资料的真实差异、项目版本和作者 | 带证据的待评估事项及固定版本的历史快照。 |
| 验证统计与输出 | 当前项目、筛选和报告类型 | 各分子、分母、来源、实际状态、XLSX 台账及 DOCX 草稿。 |
