| 宿主 / 入口 | 实际表现层 | 现有内容与设计交接 |
| --- | --- | --- |
| 全局工作区 | `ReferenceWorkspace` / `MainForm` | 项目选择器、工作模式、一级模块、各模块的二级入口。 |

## alpha.3 资料入口

`EngineeringDataForm` 由项目中心、PLC 变量管理和 DCS 原文预览区打开。Tag 台账页含查询、分页、排序、手工编辑、来源定位、版本比较与导出。资料页含导出文件读取、对象列表、原文跨度、版本比较、映射预览、确认导入及错误详情。`EngineeringFieldsForm` 提供命名字段映射、Tag 编辑及版本选择。「第三方 MCP」加入「允许 AI 申请」。

## alpha.4 验证入口

| 位置 | 工作区 |
| --- | --- |
| 验证中心 → 打开验证工作台 | 保留已有阶段计划进度。工作台使用当前项目。 |
| 经典工程项目舱 → 验证工作台 | 复用同一个 WinForms 工作台。 |
| 工作台 → 总览／阶段与计划／验证文件 | 查看业务统计，配置范围，记录源文件及版本。 |
| 需求管理／设计引用／风险评估 | 录入、提取预览、版本、关联及审核。 |
| 测试方案／测试用例／测试步骤／执行记录／证据库 | 管理设计、人工执行及其证据。 |
| 偏差管理／CAPA／Punch List／审核记录 | 处理开放项、复验和人工审核。 |
| 追踪关系／RTM／变更影响／验证基线 | 双向追踪、查缺、比较和历史快照。 |
| 合规辅助／交付资料／报告导出 | 记录检查依据、适用性与来源，检查项目交付项并生成草稿。 |

## alpha.5 仪表资产

「现场工程 → 仪表资产」和「工程上下文 → 仪表资产」打开当前项目台账。统一工程 Tag 的「关联仪表」按选中的 Tag ID 查看和录入。台账提供筛选、编辑、资产修订、校准维护、来源核验、导出和恢复。长操作可取消，项目范围变化时关闭视图。 [操作流程](../V5-ALPHA5-INSTRUMENTS.md) · [服务契约](../INTERFACE_SPEC.md#工程与验证)
