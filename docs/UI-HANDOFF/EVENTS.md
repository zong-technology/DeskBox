# 事件与线程

| 来源 | 时点 | 设计接入 |
| --- | --- | --- |
| 工程切换 | 项目 ID、资料路径或权限等范围发生变化 | 更新共享项目快照，清空旧附件授权、切换会话、取消旧请求并刷新其它工程视图。 |
| `ChatService.Changed` | 保存会话、步骤内容或活动任务有变化 | 做消息与会话列表重读。事件可能从工作线程触发。 |
| `ChatService.MessageDelta` | 已收到文本流并合并增量 | 合并渲染，使用当前任务／会话 ID 排除旧通知。 |
| `ChatService.StatusChanged` | 正在连接、接收、等待人工、工具运行、完成、失败或取消 | 在表现层线程更新。状态文本适合显示，业务判断用任务状态枚举值。 |
| `AgentRuntime.Run` 的回调 | 记录已创建、回复开始、接收全文快照、单轮结束、工具返回 | 工作线程同步调用。确认交互需返回明确允许或拒绝。可忽略未订阅事件。 |
| `AiEnvironment.Changed` | 用户切换 network/local | 终止与原环境绑定的操作，随后加载该环境的服务商、授权和会话。 |
| MCP Gateway 返回 | Detect/Invoke 实际结束后 | 一次结果同时返回即时响应、回执及可用目录。调用期间 UI 展示进度并保持可取消。 |
| MCP 注册冲突 | 同一配置发生并发修改或服务仍运行 | 保持已有调用的权限快照。刷新后重试配置编辑。 |

取消是请求。显示最终状态前，等待服务返回回执。窗口卸载时丢弃不再属于当前工程的晚到更新。
