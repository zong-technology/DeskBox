# AI 授权实时更新修复

## 本批修复

- 聊天页不再只在首次创建时读取授权快照。每轮模型上下文、每次文件工具校验均读取最新持久授权。
- 设置增加/移除目录、切换 AI 文件访问总开关会通知现有聊天服务；不用重启聊天页。
- 撤销目录会移除其内部的临时单文件/目录授权，权限变更取消正在进行的请求。
- 文件访问总开关已真正进入工具校验；关闭后，授权目录与临时文件也不能绕过。
- 新增“撤销临时文件授权”；总开关放到授权页顶部。授权目录文本可选中复制，长路径不再覆盖移除按钮。
- 根目录保留 `C:\`/`D:\` 形式，避免 `C:` 被解释为相对当前工作目录。
- 授权文件使用原子替换，失败保留旧文件并向设置页回报，不能只记日志后显示保存成功。
- 系统提示明确本轮权限优先于历史对话；文件工具失败后仍可向 AI 回灌原因，允许解释或尝试其他已授权工具。
