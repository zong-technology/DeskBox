# DeskBox 5.0.0-alpha.1 · 工程工作区指南

## 每天开始工作

1. 在「项目中心」选择或新建项目并关联工程根目录。使用顶部选择器切换项目。选择「未绑定工程 · 全局工具」可查看旧版未绑定历史和全局工具。
2. 在「项目中心 → 工程上下文」填写工程阶段、版本、当前任务及 PLC、DCS、验证资料路径。工程路径可填已存在的文件或目录，且必须位于当前项目内。手动录入的信息会在重启后保留。
3. 在「工程驾驶舱」查看近 7 日到期任务、逾期、已录入的加权进度、未关闭现场事件和索引内最近变更的文件。验证覆盖率需要后续的需求追踪数据。
4. 用 `Ctrl+K` 打开全局命令。顶部工作模式分别进入 PLC Studio、现场工程、验证中心和项目中心。它们共享项目数据。导航按钮可用键盘激活，左上角可展开模块名。天气、计算、工作记录、剪贴板和经典工作台从「工具」进入。
5. 如需全局查找，先切换到「未绑定工程」。项目内检索、文件树、AI 附件和工程资料入口会限制在当前项目。已有子目录另建为项目时，父项目不会浏览子项目中的文件。

## 工程与 AI

- 「PLC Studio」复用现有 AML、XML、SCL、UDT、DB、CSV 读取与 TIA 工作台。导出文件可以离线分析。通过「发现打开的工程」可在持证 Windows 上选择授权的 V20 工程并只读读取。需编译或新增单块时，仍使用已有隔离副本和显式审批流程。
- 「DCS Studio」从项目所绑定的 DCS 路径列出已索引文件。双击或按 Enter 可读取 UTF-8、带 BOM 的 Unicode 文本开头 64 Ki 字符。错误、文件缺失和预览截断有单独提示。
- 「验证中心」查看和维护现有验证阶段、加权进度及模板草稿。阶段进度基于用户录入。
- 「AI 工程中心」按项目 ID 和现有 AI 环境筛选会话。换项目会停止旧请求并清除临时附件和目录授权。历史未标项目的会话仍位于全局范围。
- 工程默认仅可使用数值回环地址的本机模型。要为特定项目使用外部模型，在「工程上下文」打开外部 AI 开关。文档正文仍受文件访问与获授权路径约束。没有可用模型时，在项目会话输入文件名关键词或「查找：关键词」，会按本地索引返回实际路径。
- 「AI 工程中心 → MCP 管理」可保存 TIA 服务策略、运行协议探测和查看当前范围的最近一次回执。探测通过表示私有进程完成了协议协商和工具发现。实际 Siemens 服务是否可用，由 TIA 工作台的环境与工程操作回执单独确认。

## 架构与数据兼容

V5 第一阶段保留 .NET Framework 4.8、WinForms、原生 TIA 反射工作进程、现有同步接口及 Inno Setup。选择增量架构以保留已有 Windows 部署方式。项目选中状态由 `WorkspaceStore` 持有，`ProjectContext` 提供工程路径、权限及成员规则的快照。工作台、AI 和 PLC 分别使用该快照约束文件访问、数据查询和作业目标。

| 数据 | 首次启动与兼容行为 |
| --- | --- |
| `engineering-workspaces.json` | 新字段按需写入，原任务、项目、验证阶段和 ID 保留。空路径由用户配置。历史任务中仅唯一匹配的项目名称可以进入项目页面，重名任务保留供全局处理。 |
| `engineering-current.json` | 支持显式未绑定。保存先写同目录临时文件，再原子替换。项目配置和选中状态保留上一可读取版本，发现损坏时保留原文件并显示恢复提示。 |
| `chats.json`、`chats-local.json` | 沿用既有环境文件，新会话附带项目 ID。旧记录未标项目时继续在未绑定工程范围保存。 |
| `project-tia-<项目 ID>/` | 新建项目内 TIA 草稿、作业、回执和恢复副本按项目存放。早期无项目封装的数据仍可从全局范围查看。 |
| `tia-mcp-policy.json` | 保存本机服务与离线工程策略。只有当前审批作业的工具通过 MCP 暴露。配置损坏时自动关闭该入口，重新保存策略后可恢复。 |

工程文件路径边界基于 DeskBox 当前 Windows 用户能访问的目录及项目配置。正式多用户分权、证据签核和受监管审计追踪需要独立实施和验证。运行日志用于诊断与回归。

## 安装、备份与回退

- 安装候选版前，退出托盘中的 DeskBox。在「系统设置」的数据备份区先保存数据副本。备份和升级测试只使用独立测试目录。
- Windows 需要 .NET Framework 4.8。候选安装由仓库的 Inno Setup 脚本构建。核对 Windows 测试产物中的 `SHA256SUMS.txt` 后再使用相应安装包。
- 安装器保留同一路径的上一版本；退出 DeskBox 后，从 PowerShell 运行 `tools/rollback-install.ps1 -InstallDir "<DeskBox 安装目录>"` 进行版本回退。安装目录与数据目录分别处理。
- 如果需要恢复旧版数据，在备份中心选用升级前生成的备份并重启。保留一份 V5 数据副本，以便后续读取 V5 会话和 TIA 作业。
