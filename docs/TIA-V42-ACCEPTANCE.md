## 八项验收案例

| 案例 | 已取得的证据 | 仍需验收 |
|---|---|---|
| 1. 读取现有 S7-1200 工程 | 导出资料能读取设备、程序块和变量，并保留文件及行号。V20 专用会话源码包含设备、PLC 软件、块、变量表、类型和子网枚举。 | 在有许可的 V20 主机打开真实独立 .ap20 的副本，逐项对照设备、块、变量及类型。 |
| 2. 新建模拟量缩放 FB | 工作台提供 SCL、输入输出声明、测试输入和预期输出。模型 JSON 草稿经同一 SCL 解析器检查。 | 用真实样本编译 FB，记录 Siemens 诊断。用仿真或测试台运行向量，分别记录功能结果。 |
| 3. 分析现有 FB | LAD/FBD 夹具测试覆盖接口、局部符号、导出的连线端点、块调用和双向项目引用，分析界面带文件及行号。 | 用真实 SimaticML 对照网络及执行条件，并用已配置模型确认解释与来源一致。 |
| 4. IO 清单与硬件建议 | CSV 测试覆盖地址占用避让、各变量表共享同一 PLC 地址空间、信号点数及未知订货号标记。 | 用实际 CPU、模块订货号、固件、槽位和硬件目录核对兼容性。现有能力为建议和目录查询。 |
| 5. 经批准修改副本 | 文件级检查覆盖快照、二进制副本和源文件保留。审批检查要求目标 PLC 控制器下只新增批准的 FB，已有已读对象指纹必须一致。 | 在 V20 真实样本中新增模板、编译、复读、保存并重新打开。核对差异和原工程目录哈希。 |
| 6. 语音查询和定位 | Windows 测试通过实际工具注册表调用只读查询，校验授权、对象来源和分析页联动。 | 用目标麦克风、实时模型和播放设备验证语音查询、解释及打断。通话与工程工作台同屏展示待扩展。 |
| 7. 在线写入禁用 | 工具注册表拒绝 TIA 写入请求。连接器测试确认下载请求在探测环境之前即被拒绝。 | 软件拒绝路径可在无 PLC 环境复查。 |
| 8. 无 TIA 环境 | 自动化覆盖导出资料解析、静态检查、IO 规划、草稿接口及缺少 V20 时的明确失败提示。Windows 工作台测试用无 Siemens 环境执行。 | 可在目标用户电脑覆盖安装后复查。 |

## V20 原生复验

使用已关闭的独立 S7-1200 V20 项目。先在 TIA 里记录若干唯一的设备、块和变量名称。按环境说明运行验收脚本，分别使用新的证据目录执行读取、编译和批准新增缩放 FB。[环境说明](TIA-V42-ENVIRONMENT.md) · [验收脚本](../tools/tia-v20-smoke.ps1)

传入脚本的 ExpectedDevice、ExpectedBlock 和 ExpectedTag 会与连接器实际枚举的唯一对象匹配。批准写入流程再从保存结果创建独立检查副本，验证 FB 可重新打开并核对已有对象。脚本记录环境、项目清单、编译状态、是否复读及源文件清单是否一致。详细回执在每个作业的 result.json，审批变更在 diff.txt。设备目录、PLCSIM、真实语音和现场验证各自留存证据。
