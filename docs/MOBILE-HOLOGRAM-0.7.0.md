# DeskBox Mobile 0.7.0 · 全息实时语音（build 8）

本次升级现有 iPhone 原生应用（iOS 17+），保持 `com.deskbox.mobile`。任务、项目、事件、云账号、离线队列与原有电脑中继文字 AI 继续保留。

- AI 页面新增「全息 AI 通话」，直接进入全屏多色光场和实时字幕。青蓝外层、紫色光丝、暖色核心及独立轨道按声音与倾听/思考/播报状态变化；停顿时平滑回落，打断时清除旧波纹。系统减少动态设置与应用开关都生效。
- 在 AI 菜单或首页连接设置中的「全息语音」保存名称、角色、Gemini Live / 千问 Omni Realtime 地址、实时模型及密钥。保存一次，后续进入自动读取；通话画面不显示配置表单。缺少配置时只显示投影，不启动麦克风。
- 手机全息通话直接连接所选实时服务，密钥只存本机 Keychain，不上传私人云，也不从 Windows 自动传输密钥。原有文字中继 AI 仍使用电脑配置，电脑服务密钥继续留在电脑。
- 可说「展示未完成任务」「把项目进度投影出来」「把建议列三点」或「收起投影信息」。查询来自手机已同步的任务、项目和事件缓存，返回数据来源与最近成功同步时间；不宣称缓存等于设备实时测量。投影是文字要点，最多480字/8行，显示5–120秒，不提供修改文件等操作。
- 轻点投影打断/恢复，左上角静音，右上角退出。进入后台、音频被系统打断或输出设备断开时停止声音和网络会话；回到前台后轻点继续，不在锁屏后台持续录音。
- AI 菜单的「全息通话记录」可查看、复制和分享转写。每次记录保留本次名称、角色、实时模型及被打断的回复；本机保留最近50次、每次最多200条消息，不录制原始音频。旧文字聊天文件与同步数据不迁移、不删除。

安装 `DeskBoxMobile-0.7.0-unsigned.ipa` 前，需要沿用原 Apple 签名团队与 Bundle ID 重新签名并覆盖安装，保留配对、Keychain 和离线内容；不要先卸载。未签名 IPA 不能直接点开安装，也不是 App Store / TestFlight 分发包。

GitHub macOS 工作流执行 Foundation 协议/记录/工具/动态检查、真实 iPhoneOS arm64 构建，以及两个原生 iPhone 模拟器的全息、记录和设置启动截图。截图使用明确标记的模拟预览，不连接付费服务、不启用麦克风。真实麦克风、扬声器/蓝牙路由、账号服务和端到端通话需要签名后的真机验收。
