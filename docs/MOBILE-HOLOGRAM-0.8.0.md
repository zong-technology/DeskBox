# DeskBox Mobile 0.8.0 · 布局与语音稳定性（build 9）

本次更新现有 iPhone 应用（iOS 17+，`com.deskbox.mobile`）。优先修复查询项目、任务后长播报卡断的问题，并调整首页、任务、项目、事件、AI、连接设置、每日简报和同步冲突页面。

- 修复将 12 秒播放缓存溢出当成会话故障、短时收音上传积压直接终止通话的问题。播放按真实音频时钟排队，模型查询等待及音频空隙后可接续。缓存最多保留 180 秒待播 PCM；达到上限只限制本轮新增声音，不关闭连接，文字继续记录。
- 默认播报时抑制麦克风回声和尾音，减少扬声器声音被识别为用户插话。点击投影或字幕下的“打断后提问”接话；戴耳机可在普通设置打开“允许免按键打断”。该选项默认关闭，原有名称、角色、密钥保持。
- 收音上传移出界面线程；短时积压可缓冲，超过时效的声音丢弃并提示重复最后一句，避免延迟的旧声音触发错误轮次。网络彻底断开或系统撤走音频仍会暂停，手动重连。
- AI 页改为紧凑入口、可滚动对话及随键盘抬升的底部输入栏；更多操作统一在菜单。支持把文字聊天“保存并新建对话”，在“对话记录”与全息记录一起查看；全息转写自动保存。
- 项目长名称单独占行、进度限制在 0–100%，详情值可换行。任务新增改为完整编辑表单，保存前检查同步期间的更新或删除，保存失败可重试。页面统一深色背景、间距和内联标题；小屏及大字号布局纳入验收。
- 修复文字 AI 离页/返回时旧异步请求更新新状态的问题；无法读取的原记录保留，不自动覆盖。
- AI 菜单 → 通话诊断，可查看与导出本机最近一次会话的连接、系统打断、上传丢帧及缓冲事件。仅保存固定状态和数字，不记录音频、转写、密钥或服务地址。

全息仍为原多色光粒子风格，直接在软件内进入，仅显示投影、字幕、临时信息及必要通话控制。临时信息由模型工具调用展示；任务、项目和事件读取手机最近同步缓存。名称、角色、Gemini Live / 千问 Omni Realtime 在普通设置配置一次；密钥存在本机 Keychain，电脑文字 AI 的密钥继续留在电脑。

安装 `DeskBoxMobile-0.8.0-unsigned.ipa` 需沿用原 Apple 签名团队及 Bundle ID 重新签名并覆盖安装，保留配对和离线资料；不要先卸载。此 IPA 未签名，不能直接点开安装，也不是 TestFlight 包。

验收包含原生 AVAudioEngine 离线渲染长回复、等待后播报、播放间隙、回声门控、640 毫秒积压；协议、历史、离线保存和冲突规则；真实 iPhoneOS arm64 构建；两种 iPhone 模拟器的键盘/全息返回/任务保存/五个 Tab 交互及页面截图。全部使用合成资料，不访问付费模型。真机麦克风、扬声器/蓝牙、账号服务及真实端到端通话仍需签名后测试。
