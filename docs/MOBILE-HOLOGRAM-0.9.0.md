# DeskBox Mobile 0.9.0 · 全息实际操作与工具卡片

- 全息工具和对话记录默认显示折叠摘要。展开后先看任务、项目或问题清单，原始 JSON 另行折叠；旧记录也适用。文字 AI 的执行过程使用同样的卡片，朗读只读自然语言回答。
- 全息助手可直接新建和修改任务、记录现场问题、更新处理措施。用户指定项目时先定位真实项目；不唯一时询问选择，更新时检查最新版本，重复函数 ID 不重复创建。
- 保存通过原有离线数据与同步队列完成，退出重开保留。工具区分“手机已保存”和“等待同步”，同步冲突仍使用原有处理界面；不把排队上传说成电脑已收到。
- 手机文字 AI 与电脑全息 AI 接入软件已有操作目录。手机全息可通过已配对云账号调用在线电脑的文件、文档、工程工具、页面和已配置工作流。无需再次调用文字模型来转发工具；电脑需要本版或更新版本，保留原有文件授权与修改确认。
- 长操作不阻塞全息语音接收。打断或退出取消等待；网络中断、超时或取消不能撤销已经完成的操作，提示先查询状态，避免重复写入。文件和电脑操作需要电脑在线；iOS 本地操作受系统沙盒约束。
- 保留多色光粒子、角色名称、实时字幕及原有千问长语音修复。名称、角色、语音密钥仍只需在普通设置配置一次。

安装 `DeskBoxMobile-0.9.0-unsigned.ipa` 需使用原 Apple 签名团队及 Bundle ID 重新签名后覆盖安装，保留配对和离线资料。不要先卸载。这是未签名 IPA，不能直接点开安装。

验收使用合成资料，不连接真实项目或付费模型。云端需完成实际 iPhoneOS 构建、离线操作与协议回归、原生音频检查、两种 iPhone 尺寸的工具折叠/键盘/任务保存交互及页面截图。真机千问、麦克风、蓝牙及私人电脑账号联动仍需安装后测试。
