# DeskBox 开发决定

| 决定 | 当前执行方式 |
| --- | --- |
| 仓库规则统领默认开发方式 | 从根目录 AGENTS.md 进入，读取当前项目状态和适用规则，明确用户任务的范围。先交付可用功能及证据，保留 WinForms 和 .NET Framework 4.8，大规模视觉重构安排在 beta。 |
| 托管 Windows 验收限定环境 | GitHub Actions 为原生候选构建和隔离验收提供证据。个人 Windows 环境、授权 TIA/DeltaV 和 iOS 真机需单独记录。 |
| 源码、文档和安装产物独立标识 | 验收和 SHA‑256 与实际 Windows 受测提交绑定。决策、测试环境和剩余缺口记录在版本文档。 |
| 使用稳定 ID 建立追溯 | 项目、Tag 和业务实体独立编号。正式修订和文件哈希可用于固定来源及历史。 |
| 保留既有数据并隔离新增业务 | 验证台账和证据位于独立项目目录。版本兼容、备份校验和恢复预检按实际状态执行。 |
| 计划和结果分别计算 | 阶段进度继续沿用 ValidationProgress。需求覆盖、执行、通过、审核和交付取各自的真实记录。 |
| 授权人员负责结论 | 系统记录人工测试、复验、偏差关闭和审核。AI 读授权范围内的资料并准备草稿。 |
| 权限延伸至外部工具 | 本机 MCP 逐项核准和确认，模型按项目权限运行，验证结果留在本机。 |
