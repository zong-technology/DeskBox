# 手机 AI 与语音使用说明（0.6.0 / build 7）

1. Windows 更新至 0.6.0，保持 DeskBox 运行。在设置中启用已有 AI 服务商，确认其模型、地址、密钥有效。
2. iPhone 使用同一签名团队、同一 `com.deskbox.mobile` 覆盖安装新版 IPA；不要先卸载，以保留云登录和离线内容。
3. 两端登录已有的同一个私人云账号即可，跨网使用无需重新局域网配对。
4. 打开手机「AI&SI」，可以查询任务、项目、现场事件及电脑已授权的文档。首次请求通常需等待电脑下一次自动检查（最多约 15 秒）。
5. 点麦克风并允许麦克风、语音识别权限。普通模式将听写结果放入输入框，检查后发送。
6. 打开「连续语音对话」，停顿约 1.3 秒后自动提交，回复结束后朗读，再继续聆听。点取消、关闭开关或离开页面可停止；识别结果仍请核对专业术语与数字。
7. 文本回复可选择、复制、朗读。顶部显示等待电脑、请求模型、查询工具、接收回复及错误状态。网络恢复或返回页面后可点「恢复当前请求」。

电脑须保持联网运行；本版不在关机时独立调用云模型。手机当前提供查询分析，写入文件、修改任务、执行工作流仍在电脑端确认。文档权限沿用电脑的文件开关及授权目录，未授权内容不会因手机登录自动开放。

API Key 保留在 Windows 加密存储中，不发送至手机或私人云。请求和回复通过私人云中继；服务器在后续新请求时清理超过 7 天的中继记录，手机保留最近 60 条本地消息。设备撤销会同时取消其未完成 AI 请求。

手机切到后台会停止本机轮询与录音，电脑可继续生成，返回前台再恢复；不宣称锁屏后持续录音或后台实时对话。语音识别优先使用设备支持的本地识别，否则可能使用 Apple 服务。

Xcode 已成功编译 iPhoneOS arm64 真包；麦克风权限、蓝牙音频、连续对话与朗读体验需在签名后的真机确认。
