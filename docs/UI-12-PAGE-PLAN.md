# 用户指定的12页视觉重构

顺序：先修复现场事件同步、Win+F呼出、AI读取/管理应用数据和文件能力；验收并交付修复版后再实施此视觉任务。插话新增事项不替换既有任务。

参考图：`assets/ui-reference-12-pages.png`，用户于2026-11-03提供。该图是布局、主色和控件组织的视觉依据，不把图中的演示数字、虚构文件或项目当作真实业务数据。

| 序号 | 目标页面 | 当前对应功能 |
|---|---|---|
| 1 | 智能桌面（首页） | 首页与智能桌面入口、工具快捷启动、最近文件、项目进度 |
| 2 | 工程项目舱 | 真实项目卡片、分类、项目搜索、新建项目 |
| 3 | 项目详情 | 当前项目进度、验证节点、文件页签及项目资料 |
| 4 | 工程工具矩阵 | 分类工具卡片、PLC/DCS/HMI/验证工具入口 |
| 5 | 4-20mA / 仪表计算 | 输入区域、即时结果、量程可视化 |
| 6 | AI&SI助手 | 服务商/模式切换、真实工具流程和对话输入 |
| 7 | 自动化工作流 | 工作流列表、节点链、预演/执行 |
| 8 | 文件搜索 | 搜索条、筛选、文件表格、操作入口 |
| 9 | 任务与提醒 | 状态指标、页签、任务表格、提醒 |
| 10 | 现场事件 | 状态与严重级别、工程上下文、处理状态 |
| 11 | 天气 | 城市、实况、逐小时/逐日预报 |
| 12 | 移动同步 | 云与局域网状态分开、设备授权、同步队列 |

统一验收：导航与顶栏、卡片比例与间距、蓝青色主题、字号与文字可见性、表格行高与对比度、空/加载/错误状态、常用分辨率/DPI及键盘操作；逐页截图比对后再标记完成。
其他既有页面保留在辅助入口，不因12页主布局而删除功能。

当前状态：0.5.0已实现12页原生布局与业务接入，完成12页截图和23项专项，完整回归39套645项通过。该状态表示布局/交互验收，不宣称与低分辨率拼图逐像素一致；项目独立配图等细节继续保留为后续精修。
