# 手机任务与同步使用流程完善

本批完成的是手机端源码和对应 Windows 桥接修复，未宣称 iPhone 安装包已交付。

## 源码变更

- 任务页支持标题/备注搜索、全部/未完成/已完成筛选。
- 新增任务过滤空白标题；点击圆形图标完成或重新打开，点击任务编辑。
- 编辑可改项目、优先级、截止日期、备注、完成状态；日期严格校验 yyyy-MM-dd。
- 滑动删除需确认，并写入待上传删除标记；未同步编辑保留在本机队列。
- 首页显示真实同步忙碌状态与待上传数量；禁止配对/同步重复并发。
- 显示过期/撤销授权、异常数据的明确提示；失败保留待上传内容。
- 清除此手机配对只清除 Keychain 凭证，不删除离线数据；电脑设备撤销仍由电脑操作。
- 请求结束释放 URLSession；凭证保存改为先更新后新增，失败不假报配对成功。
- 本地数据解析失败保留原文件并暂停写入/同步；保存失败显示错误，避免静默覆盖损坏数据。

## Windows 桥接修复

- 旧手机记录没有任务更新时间时，采用同步记录时间，避免完成日期为零。
- 取消完成清除旧 DoneAt；不匹配记录 ID 不写入其他任务。
- 项目进度增加兼容可选的 ProgressApplicable 标记，N/A 不再显示成 0%。
- 项目快照使用实际更新时间，而非最近打开时间。
