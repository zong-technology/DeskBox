## 完成的行为

- 手机文字 AI 直接连接千问/OpenAI 兼容接口或 Gemini，使用本机任务、事件及附件；不要求电脑版在线或登录同步账号。电脑文件及工作流通过默认关闭的可选能力保留。
- 本地隔离和网络开放分别保存模型配置、密钥及对话；电脑永久目录授权也分别保存，切换清除临时授权。关闭手机网络环境不依赖钥匙串可写；保存新的网络密钥仍需成功存入系统钥匙串。
- 本地环境在执行处拒绝外部模型、网页、电脑中继、网络共享、映射盘及重解析路径，暂停设备同步。普通 AI、旧版摘要、文档解析、实时语音、工作流 AI 和手机中继均经过实际执行边界；角色文本不能改变权限。
- 手机本地生成使用可用的 Apple 本机模型，本地全息使用设备内听写和系统朗读。设备不支持时显示实际原因，不回退云端。电脑本机模型接受数字回环地址，保留原有文件确认；本地文档解析使用本机 Python 绝对路径。
- 网络环境提供 HTTPS 网页正文读取、来源及截断范围；请求不跟随跳转，网页不携带模型凭证。更改自定义模型地址不能自动借用原服务密钥。
- 升级前的未确认电脑请求不阻塞新手机问题，也不会把尚未确认的旧写入指令重交手机模型执行。迟到的全息记录只写回原环境，不混入新环境。
- 音频缓冲完成解码后按播放器采样时钟显式排程，停顿后增加有界的启动余量。原生离线验收先给播放器正常的异步调度周期，再快进虚拟采样时间，仍检查完整输出样本。

业务任务、项目和事件仍共用，恢复网络后按原设置同步。隔离面向 AI、工具、授权及同步，不是操作系统防火墙或外部模型程序沙盒。
