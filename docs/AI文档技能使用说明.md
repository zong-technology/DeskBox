# AI&SI 文档技能

本技能安装在 DeskBox 程序内，随 EXE 嵌入，不需要在 Codex 中额外安装技能才能使用。
解析使用本机 Python 3.12+、openpyxl 和 PyMuPDF；本机已经通过运行时检查。
换电脑后先执行 `tools/install-document-skills.ps1` 安装依赖，
也可设置 `DESKBOX_DOCUMENT_PYTHON` 为指定 Python 的完整路径。

## 使用

1. 退出旧版 DeskBox，从最新构建 `dist/current-review/DeskBox.exe` 启动。
2. 打开 AI&SI，在右侧工程上下文栏点击“添加文档”，选择 PDF、DOCX、XLSX 等文件。
3. 输入问题，例如“找出这份协议里的报警接受标准，引用页码或工作表行”，点击发送。
4. AI 会调用 `doc.read`，工具结果卡片显示实际读取内容，随后模型根据正文回答。
5. 想搜索目录下所有文档：先在“设置→文件与隐私”授权项目目录，再让 AI
   “在 D:\项目资料 中按正文搜索‘联锁接受标准’，列出文件路径与出处”。
6. 可以从智能桌面的文件预览中点 Ask AI&SI，该操作授权所选文件；不会自动授权同目录其他文件。

“文档技能”按钮显示应用内技能说明。添加文件只是授权并填入提示，点击发送才读取。
阅读所选资料不要求目录级授权；目录搜索和新建输出路径要求授权目录。
文档正文会作为模型上下文发送到当前配置的 AI 服务商，请只选择允许提供给该服务商的资料。

## 格式与边界

| 格式 | 读取 | 写入 |
|---|---|---|
| PDF | 提取文字，带页码 | 新建简单文字 PDF，支持中文 |
| DOCX | 正文、表格文字、页眉页脚、脚注，带段落来源 | 新建文字 Word 文档 |
| XLSX / XLSM | 所有工作表的非空单元格，带表名、行、坐标 | 新建 XLSX，TSV 分列；不运行宏或重算公式 |
| TXT / Markdown / CSV / TSV | 读取真实文字，支持 UTF-8、UTF-16 BOM、GB18030 | 新建对应文本格式 |
| VSDX | 页面和形状文字，带形状 ID | 图形编辑尚未实现 |
| DOC / XLS / VSD | 需先转换为新版格式 | 不生成伪装扩展名的文本文件 |

扫描版 PDF 可调用 `doc.ocr {path,page=1}` 使用 Windows 本地 OCR 按页识别；需要已安装的 Windows 识别语言。本机中文引擎已通过实际图片样本测试。OCR 不是原始文字层，关键数值应核对原件。
加密 PDF 需要先解密。新建文档输出不会覆盖既有文件，也不保留原文档复杂排版。
读取图表的形状、图片内容、嵌入对象、公式计算结果和完整 Visio 拓扑不在本批提取范围。

单文件上限 64 MB；正文提取上限 100 万字符；Excel 上限 20 万单元格。
每次 doc.read 默认 16000 字符，返回截断提示时，模型应按 NextOffset 继续读取。
目录内容搜索最多扫描 100 个支持文件，达到命中上限会明确显示 Incomplete；应缩小子目录继续。
单次解析 30 秒超时；不会执行文档中的宏、代码或命令。

## 工具接口

- `doc.read {path, offset, maxChars}`：读取有出处的正文。
- `doc.search {root, keyword, limit}`：按内容搜索，返回 Path/Source/Excerpt。
- `doc.create {path, content}`：确认后新建文件；Excel 内容用制表符分列、换行分行。
- `fs.read` 已接入同一文档读取器，旧调用也能读取 Word/Excel/PDF。
- `doc.summarize` 的本地摘要与对比也改用实际提取文字，输入截断会标记。

本批文档专项测试使用真实格式的新建文件、损坏文件和扫描件空正文用例。
对话闭环测试使用本地模拟模型，验证工具结果进入后续上下文，不代表真实 AI 服务商的语义准确率。
