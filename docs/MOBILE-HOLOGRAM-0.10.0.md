# DeskBox Mobile 0.10.0 · 任务同步与删除修复

保留 0.9.0 的全息风格、折叠工具结果、名称、角色和语音配置。

新增手机文字 AI 附件：右上角回形针可选择 PDF、图片、TXT/Markdown/CSV/JSON 文本。手机本地提取 PDF 或识别图片文字，发送前可展开预览和移除；发送时通过已有电脑中继传入提取文字，原文件不自动上传。每条支持一个不超过 10MB 的附件，PDF最多读取前8页，提取文字最多12000个UTF-16单位，截断会明确提示。图片识别结果需核对数字和单位；不冒充图片构图分析。附件内容随文字对话与归档记录保留。

- 修复手机任务的负责人在电脑回传时丢失的问题。配套 Windows 测试版 10 保留负责人、备注和修改时间，读取快照不会仅因 JSON 字段顺序不同而制造新版本或假冲突。
- 手机任务列表与全息任务查询支持按负责人搜索；电脑普通 AI 与全息 AI 可读取、设置或明确清空负责人。
- 删除任务确认期间如果记录已被另一端修改，将保留新记录并提示重新查看。保存失败时回退任务、上传队列和冲突状态，错误在任务页显示；保存后重启仍保留删除标记。
- 配套 Windows 测试版 10 对同一次全息修改请求保留执行回执，网络重发不会再次创建任务或执行同一操作；同一请求 ID 携带不同参数会被拒绝。普通查询仍读取最新数据。

请两端一起升级。手机文件为 `DeskBoxMobile-0.10.0-unsigned.ipa`，仍需沿用原 Apple 签名团队与 Bundle ID `com.deskbox.mobile` 重新签名并覆盖安装，不要先卸载。电脑操作需要对应电脑在线及已有授权。

自动化使用合成数据和模拟模型；真机千问/Gemini、麦克风、蓝牙、私人电脑账号联动以及 Windows 125%/150% 缩放需在目标设备验收，不能以模拟器代替。
