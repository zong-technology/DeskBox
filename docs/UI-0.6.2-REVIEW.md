# DeskBox 0.6.2 — 项目概览与任务月历

本轮继续处理 0.6.1 未满足的页面组织问题，重点改变项目页和任务页的实际使用方式。

- 项目管理：目录卡片 / 表格与右侧概览并列；选择项目即可查看真实总进度、八组交付阶段、下一未完成节点、目录和备注。选中项目有边框标记，保留类型、关键词过滤和进入完整项目工作区的操作。窄窗口概览支持滚动。
- 任务：增加月历 / 列表切换、月份切换、截止任务数量、紧急标记、当天任务列表；打开当天任务可在右侧继续编辑。月历读取原任务数据，保存仍通过现有并发检查和同步接口。
- 新页面接入已有主题、导航与详情样式；更新未清空项目、任务、事件和云账号。

验证：全量 40 套、672 项通过；最终界面专项 37 项通过。覆盖项目检索、任务保存与并发保护、月历存在与翻月点击、原有计算/工作流/导航及布局切换。截图包含 1920×1080 的 12 页，以及 1280×800 的项目详情、任务月历。安装包和实际安装 EXE 校验相同。

本轮不把自动化检查等同于用户已经认可完整视觉效果，也未宣称原 V3 的所有待办均已完成。其他页面沿用 0.6.1 的改造；完整规格的剩余项继续保留。

启动请使用桌面“桌匣 DeskBox”或 `D:\DeskBox\DeskBox.exe`。升级检查发现当时运行的程序来自 `Windows-0.6.0`，该目录保留作旧版回退用途。

升级前对真实 data 做逐文件校验备份，位于交付目录 `数据备份/0.6.2升级前-*`。退出软件后可用旧安装包回退程序，勿删除 data。iPhone 继续兼容原 0.6.0 包。
