# DeskBox 0.6.1 — UI 重做与复核

本轮针对 0.6.0 仍显平、导航按钮堆叠、工程页面空泛、窄窗口操作被挤出的反馈进行了实际界面重做。保留原业务与云端协议，iPhone 继续使用 0.6.0 (7)。

## 本轮变化

| 页面 / 区域 | 实际变化 |
|---|---|
| 全局 | 侧栏改为扁平导航、当前项侧边标记；卡片中文标题优先；表格统一底色、行分隔与垂直对齐；项目上下文显示在顶栏；多主题同步更新流程图和参数表。 |
| 工作台 | 工业设备横幅、实时时钟、四个真实工作指标、项目总进度环、八组实际交付阶段、优先任务、最近打开与项目下一步。背景按比例裁切。 |
| 智能桌面 | 延续实际文件画板、目录操作与预览，使用新的工作区外框和导航；不将图片当文件桌面。 |
| 项目 | 新增同屏工程工作区：验证流程与项目文件、关联任务、备注并排显示。窄屏调整节点横向位置，文字不随图形缩小。 |
| 工程工具 | 从入口卡片改为可直接操作的工作区；缩放窗口保留输入；保留本机软件启动入口；仪表输入框具有常驻字段名和单位；4–20mA 正反算、越界显示、公式及复制结果；Pt100 与单位换算同屏。 |
| AI&SI | 保留真实三栏对话、会话搜索、附件与流式过程，接入新的导航和公共视觉样式。 |
| 文件中心 | 搜索与筛选自动换行，窄屏仍可访问操作；保留类型、列表、预览三部分，避免同时重复加载隐藏的旧预览。 |
| 任务 | 快速录入、编辑、完成、提醒和筛选自动换行；保留统计、真实列表和带同步版本检查的详情栏。 |
| 工作记录 | 更新列表底色和行对齐，保留过滤、详情与 CSV 导出。 |
| 自动化 | 三栏流程目录 / 节点与运行结果 / 参数检查；自动展示实际节点参数；参数可保存，执行期间禁止修改；提供真实预演和运行。 |
| 现场事件 | 筛选栏自动换行，保留状态统计、实际列表、可滚动详情和版本保护。 |
| 天气 / 移动同步 | 保留真实预报与真实连接数据，更新公共导航、标题、卡片和列表样式。 |

## 复核证据

- 全量回归：40 套、666 项通过。
- 最终构建界面专项：35 项通过，包括真实量程计算/越界提示、工作流参数保存与预演、项目流程内嵌、任务保存与并发保护、模式切换。
- 最终构建追加：项目进度 21 项、工程 UI 32 项、工作流 23 项通过。
- 默认截图 1920×1080，另检查 1280×800。12 页及项目详情截图位于 `shots/ui-061-review`。
- 真实安装界面截图位于交付目录，含私人项目内容，不进入版本库。
- 升级前正常退出软件，逐文件校验备份 `D:\DeskBox\data`；升级安装验证不覆盖用户资料，并保留上一版 EXE。

现有测试证明导航、计算、数据、执行和布局基础可用，**不等同于原始完整 V3 规格已全部达到商业级视觉验收**。本轮没有宣称日历、独立项目封面、自由拖放工作区布局、AI 项目上下文来源清单、事件附件时间线等未完成项已经实现。其余历史功能继续按 `V3-0.6.0-STATUS.md` 的清单保留。

## 回退

退出 DeskBox 后可使用保留的 `Windows-0.6.0` 包回退程序。任务、项目和云同步协议没有因本轮界面调整改变；勿删除 data。回退后可在设置切换经典工作台。
