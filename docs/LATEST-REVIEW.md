## 使用新版

DeskBox 使用全局单实例。先从托盘右键退出正在运行的旧版，再打开本页程序路径。
如果仍运行旧版，新文件不会热更新进程里的代码。
需要安装时，退出目标安装目录中的 DeskBox 后，在仓库运行 `install.ps1`；也可用
`-SourceExe` 指定本页通过验证的 EXE。安装不会自动退出应用或覆盖 data。
