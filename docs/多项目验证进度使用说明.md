# 多项目验证进度

## 项目与目录

打开“项目舱”→“添加项目目录”，选择项目自己的文件夹并命名。每个项目独立保存
目录、元数据、备注和验证进度。“移除”只移除 DeskBox 配置，不删除真实文件。
选择项目后点“打开”，或在主页选择项目后点“打开项目文件夹”，可直接打开该目录。

## 按流程更新进度

项目舱选中项目→“更新进度”，或主页选择项目→“编辑验证进度”。
左侧显示流程图，右侧编辑表格；左右区域可以拖动分隔线调整宽度。

流程按用户提供的图组织：项目启动→URS/SIA/CA/VP 并行签批→汇合→设计文件→
DQ 方案/执行/报告→DQ 通过判断（不通过返回设计复核）→FAT→SAT→IQ→OQ→
可选 PQ→VSR→项目交付。

每个节点均有：进度、开始日期、结束日期、备注、自动更新时间。
进度可输入 `65`、`65%` 或 `N/A`，百分比范围为 0–100。
日期使用 `yyyy-MM-dd`，可留空；填写时结束不能早于开始。
项目级开始/结束日期、项目备注和绑定目录在窗口上方编辑。
点击“保存进度”才会写入数据，取消不会修改项目。

总进度等于所有非 N/A 节点百分比的算术平均；全部 N/A 时总进度显示 N/A。
例如两个适用节点为 100% 和 50%，其他节点为 N/A，总进度为 75%。
100% 仅表示用户登记的进度，不自动生成签名、审批证据或强制执行节点先后顺序。
PQ 是否适用由项目负责人设定；图中的 DQ 分支用于呈现流程关系。

旧项目的 Design/PLC/DCS 等原始进度继续保留。首次保存新的验证流程后，该项目
总进度切换为新流程算法，历史阶段数据不会被删除或自动推测为已完成。

## 主页使用

主页上方项目下拉框切换当前项目，总进度固定显示在标题区。配置过验证流程的项目
在 PROJECT HEALTH 区显示可滚动的流程图；切换项目后回到流程起点。
“打开项目文件夹”“项目内搜索”“编辑验证进度”都作用于当前选择的项目。

## 项目内搜索

在项目舱选中项目点击“项目内搜索”，或在主页选择项目后点击同名按钮。
搜索页会显示限定项目名称与根目录；文件名、类型、日期等筛选继续生效。
子目录属于当前项目搜索范围；类似 `Project-other` 的兄弟目录不属于 `Project`。
首次搜索新绑定目录时会添加到文件索引并后台更新，索引期间结果可能不完整。
搜索基于文件名与元数据，不承诺全文解析工程程序或 Office/PDF 文档内容。
