# DeskBox Mobile 0.11.0 · 手机独立 AI 与运行环境隔离

文字 AI 改为手机直接请求千问/OpenAI 兼容接口或 Gemini，不需要电脑版在线，也不需要先登录同步账号。手机内的任务、项目、问题记录和附件提取使用原有本地存储；电脑文件及工作流作为可选连接，默认关闭。模型及密钥在「AI 环境与模型」保存一次，可沿用匹配的手机全息服务密钥。

所有 AI 统一支持「本地隔离」和「网络开放」环境。两边的文字及全息对话记录分别保存，切换会停止在途请求并清除当前输入、附件和临时授权，不把原对话自动发到另一边。本地模式禁用外部模型、网页及电脑工具，并暂停设备同步；网络模式可直接读取 HTTPS 网页正文，网页只作为资料，不带模型密钥、不跟随跳转。电脑操作仍需主动开启、已配对电脑在线与原有授权。

手机本地生成依赖 iOS 26+、受支持的 Apple Intelligence 设备、已启用并可用的本机模型；系统不支持时明确提示，保留原有离线任务/问题管理，不自动改用云端。离线全息通过设备内听写、本机模型与系统朗读工作，动态随朗读变化；设备不支持本机听写时使用文字。网络全息继续使用已配置的千问/Gemini 实时服务。

业务任务、项目与问题仍共用手机工作资料，进入网络环境后会按原同步设置上传待同步修改；隔离的是 AI 运行、配置和对话上下文，不是给每个环境复制一套项目数据库。此功能不是系统防火墙，天气及用户主动打开的外部网站属于独立功能。

IPA 内部版本 0.11.0/build 12，iOS 17+ 可安装；原生离线模型另有上述设备要求。继续沿用原签名团队和 Bundle ID `com.deskbox.mobile` 签名覆盖安装，不要先卸载。配套电脑版为 2.1.0-hologram.11。本机模型可用性、听写、扬声器/蓝牙和实际付费模型仍需目标设备验收。
