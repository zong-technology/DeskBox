# 三模式工程工作台布局（2026-11-02）

本轮重新安排首页的主要区域，并将主要功能从仅有导航名改成带说明的操作入口。

- 指挥中心：项目进度、任务、下一步行动与九个主要功能并排，活动趋势和项目统计在下方。
- 专注工作：当前任务和继续工作操作为第一视觉层级，项目上下文、最近文件与紫色功能入口辅助。
- 系统全景：工程依赖链为主，项目/验证、遥测、通知风险与功能工作区分别组织，使用绿色识别。
- 主要功能：智能桌面、项目与验证、AI 文档助手、自动化、工程工具、文件检索、任务、监测、手机联动。
- 所有入口连接现有页面；项目下拉、打开文件夹、项目内搜索、编辑进度固定在顶部。
- “信息侧栏”可展开/隐藏右侧上下文，选择持久保存。布局模式继续持久化。
- 背景图采用等比例裁切，避免设备图被拉伸。修复布局重新计算时出现无必要横向滚动条的问题。
