# 手机独立 AI 与本地 / 网络环境

手机文字 AI 和全息 AI 均可独立运行，不需要电脑版保持在线。同步账号用于业务资料同步；只有主动开启电脑操作后，电脑文件、文档和工作流才需要已配对电脑在线及原有授权。

## 选择环境

- 手机：AI 页右上角设置，进入「AI 环境与模型」。
- 电脑：「功能与设置 → AI 服务商」，顶部选择运行环境。

| 能力 | 本地隔离 | 网络开放 |
|---|---|---|
| 手机生成 | 可用的 Apple 本机模型 | 手机直接连接千问 / OpenAI 兼容接口或 Gemini |
| 电脑生成 | 数字回环地址上的本机模型 | 已保存的网络模型 |
| 语音 | 手机使用设备内听写、本机模型和系统朗读；电脑需本机兼容实时服务 | 已保存的千问 / Gemini 实时服务 |
| 网页读取 | 关闭 | 可读取 HTTPS 网页正文，手机可单独关闭 |
| 电脑文件与工作流 | 手机不调用电脑；电脑保留本地文件授权，停用工作流执行 | 手机主动开启后可调用已授权且在线的电脑；电脑保留原有确认 |
| 设备同步 | 暂停 | 按原有连接及自动同步设置运行 |

两边的文字及全息对话、模型配置、密钥分别保存；电脑的永久目录授权也分别保存。切换不把上一环境的聊天上下文自动发给新模型，临时选择的文件授权会清除。手机停止当前请求；电脑需先结束全息通话或停止文字生成。关闭网络不依赖模型钥匙串可用。

任务、项目及问题记录是共用的业务工作资料，进入网络环境后会按原设置同步待上传修改。隔离范围是 AI 请求、工具、授权及同步通道；天气、用户主动打开的网站和外部模型程序不由此功能充当系统防火墙管理。

## 手机独立联网

在「AI 环境与模型」选择网络开放，保存一次文字模型配置：

- 千问默认完整接口为 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`，文字模型默认 `qwen-plus`。
- 其他 OpenAI 兼容服务填写其完整 `chat/completions` 地址。
- Gemini 填写 API 根地址，例如 `https://generativelanguage.googleapis.com/v1beta`，另填文字模型。

可沿用匹配服务的手机全息密钥，或单独保存文字密钥。密钥只存系统钥匙串；自定义地址需要自己的密钥，不能借改地址把原服务的密钥带过去。更改模型配置会检查保存结果；没有密钥时明确提示。

手机可以直接查询和保存任务、更新完成状态及备注、记录现场问题、分析已提取的 PDF / 图片文字 / 文本附件。工具结果默认折叠，保存和同步状态分别返回。全息使用自己的实时模型配置，名称与角色在同环境中保存。

「允许调用已配对电脑」默认关闭；不用电脑时保持关闭即可。升级前遗留的电脑请求仅通过「恢复」手动查看，不占用新手机问题，也不向手机模型重发尚未确认的旧写入指令；这些旧操作的结果仍应先核实。

## 本地模型条件

手机本地生成需要 iOS 26+、受支持且已启用 Apple Intelligence 的设备，以及系统报告可用的本机模型。设备或地区不支持时显示实际状态，不自动改用云端；原有 iOS 17+ 离线任务与问题管理继续可用。离线听写也需要设备支持中文本机识别。

电脑本地模式只接受 `127.0.0.1` 或 `::1` 上的模型，不接受 DNS 别名、局域网地址或外部地址。例如已部署的 Ollama 可填写 `http://127.0.0.1:11434/v1`，模型名填写实际安装的名称；DeskBox 不捆绑模型权重。本地文档解析使用已安装的本机 Python 绝对路径，可通过 `DESKBOX_DOCUMENT_PYTHON` 指定。

本地文件工具、旧版摘要和直接文档解析均拦截网络共享、映射网络盘和重解析路径；模型和网页请求不跟随重定向。角色设定不能改变这些执行边界。

## 安装与验收

Windows 先从托盘退出旧版，再安装到原目录。iPhone IPA 继续用原签名团队及 `com.deskbox.mobile` 签名覆盖安装，不要先卸载。自动检查使用合成资料、模拟模型与原生离线音频；真实模型、Apple 本机模型可用性、麦克风和蓝牙仍需目标设备验收。
