Windows 预览版为 4.2.1-tia.3，安装包已重新下载核对 SHA-256。[下载](https://github.com/zong-technology/DeskBox/releases/tag/v4.2.1-tia.3) · [产品提交](https://github.com/zong-technology/DeskBox/commit/56dd244641945b1b72c417238b6b43b5ac7e4a53)

## 从哪里输入需求

1. 在 DeskBox 左侧打开「博图 AI 工程师」，点击顶部的「输入工程需求」。焦点会进入「AI 编程」页的「工程需求」输入框。
2. 输入目标、PLC 系列、输入输出、限制和预期结果。空白时可用「填入示例」查看一条完整需求。
3. 点击「生成工程计划」。默认 Enter 发送，Shift+Enter 换行。可在「设置 → AI 服务商」关闭 Enter 发送，改用 Ctrl+Enter。
4. 在工程助手查看接口、待确认参数、测试用例和复核项。下方编辑器可查看行号、高亮、查找、静态检查和另存 SCL。已有草稿时，再次生成会打开替换预览，点击「应用已预览草稿」后才替换编辑器内容。

可在生成期间继续写下一条需求。取消任务保留输入，重新生成使用上一次已提交的文字。「保存需求草稿」将草稿写入当前 AI 环境的本机资料目录。切换页面保留未发送的内容。默认只读针对工程副本。生成计划和载入模板会进入辅助设计模式。

「添加工程资料」和拖放支持 SimaticML、SCL、UDT、DB 与 IO CSV。勾选「引用已加载的工程」时，当前对象和可见工程摘要会作为模型上下文。文件与隐私许可及网络发送确认继续生效。没有配置模型时，可使用缩放模板、资料分析和静态检查。

## 工作区操作

| 页面 | 输入与输出 |
|---|---|
| AI 编程 | 文字与已授权工程上下文生成结构化计划及单块 SCL 草稿。可载入本地缩放模板、检查草稿和导出。 |
| 程序分析 | 左侧按名称、类型或路径筛选设备、块和变量。分组展开后加载关联对象。选中对象可查看接口、连线端点、引用和来源。右键可复制工程路径及来源。 |
| 硬件组态 | IO 清单可供模型生成设计建议。确切型号和固件需在本机 V20 硬件目录核对。 |
| 网络拓扑 | 展示已读子网及设备层级。端口连线与真实 PROFINET 拓扑需对照工程。 |
| 变量管理 | 从 IO CSV 或工程变量检查重叠，从指定 I/Q 起点规划地址。建议须按目标模块核对。 |
| 工程对比 | 用两组同类导出资料或两个 V20 工程副本生成可见对象差异。 |
| 测试验证 | 在此查看静态检查、V20 编译诊断与作业回执。「查看能力与环境」显示检测结果和操作限制。经明确批准的缩放模板是目前唯一支持写入离线副本的操作。 |

宽窗口可拖动左右分隔条。窄窗口中工程助手移到底部，可点击「收起助手」留出编辑空间。「AI 编程」页支持纵向滚动。顶部任务状态来自实际请求、确认、校验或执行结果。输入的焦点表现参考现有设计系统的 Input 状态。[Figma 输入控件](https://www.figma.com/design/jdAhri31Qx53x6T4gG4a9D?node-id=1-4836)

## 验收边界

V4.2.1 优先整改输入和工作台布局。自动化分别启动真实 EXE 发行包安装后的应用与合成资料测试宿主。模型交互测试使用本机回环端点。Windows 输入法拼音候选提交及 125%、150% 实际系统缩放须另留目标机证据。

- 58 项 Windows TIA 工作台检查通过，覆盖鼠标点选、剪贴板、快捷键设置、草稿保留、生成期间输入、工程树筛选和确认后应用预览。1920×1080、1600×900、1366×768、1024×768 覆盖了工作区交互，实际为 96 DPI。[Windows 回归与分页面截图](https://github.com/zong-technology/DeskBox/actions/runs/44506369108)
