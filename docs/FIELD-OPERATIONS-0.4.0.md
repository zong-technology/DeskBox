# DeskBox 0.4.0：现场事件与手机冲突处理

## 已确认的基础能力

2026-11-03，用户确认账号已连接并可自动同步。此次沿用现有云服务和设备授权，不需要重新部署 Worker 或重新配对。
此确认不替代不同网络切换、长时间离线和新功能的真机专项测试。

## 新增功能

### 现场事件两端处理

- Windows 左侧新增“现场事件”：新建、搜索项目/设备/现象/负责人，按处理状态筛选。
- 电脑与 iPhone 均可维护：关联项目、设备/位号、负责人、S1–S4、现象、调查/根因和处理措施。
- 流程状态：待处理 → 调查中 → 已解决 → 已关闭。解决/关闭前必须填写处理措施，不把保存动作当作验证结论。
- iPhone 新增详情编辑；发生时间、更新时间和既有记录保留。电脑修改通过原有同步服务回传手机。
- 事件复用已有同步存储，不另建相互独立的事件数据库。
- 编辑窗口保存前检查版本；另一端已更新时拒绝覆盖，编辑内容保留在窗口供用户复制或核对。
- 局域网与账号云提交均校验事件 ID、描述、严重程度、状态及关闭措施。

### 手机冲突比较与选择

- 同步引擎明确返回 Conflict 后，首页出现“处理N项同步冲突”入口；普通待上传不会冒充冲突。
- 对比手机和电脑的任务/事件字段，包含远端删除标记。
- “保留手机版本”：以所展示的电脑版本为基准重新提交；“采用电脑版本”：采用其内容，并提交版本确认以关闭旧冲突。
- 两种选择均再次检查本地编辑时间和远端版本。对比期间数据变化会拒绝旧选择，不能静默覆盖更新。
- 冲突及本地待上传队列落盘；退出/重启后可继续处理。未知或损坏的远端内容不用于清除本地修改。
- 选择后的提交仍由原同步引擎做版本检查；此时电脑离线会继续等待确认。

## 升级与入口

- 电脑：退出托盘中的旧程序，用 `dist/field-0.4.0/DeskBox.exe` 覆盖原位置的 EXE，保留同目录数据及原数据目录配置。
- 手机：`dist/ios/DeskBoxMobile-0.4.0-unsigned.ipa`，按原团队和 `com.deskbox.mobile` 覆盖签名安装，勿先卸载。
- 本批不修改正在运行的旧程序，也不触碰真实业务数据；测试使用隔离样本目录。
- 云端配置、已有任务/项目、通知设置和设备凭证继续沿用。
