# DeskBox 2.1.0-hologram.10 测试更新

修复手机任务负责人同步到电脑后被丢弃的问题，普通 AI 与全息 AI 可查询、设置或清空任务负责人。回传时保留备注与最新修改时间，不再因两端 JSON 字段顺序不同而反复生成新版本和假冲突。电脑重启后，在首次同步前删除的任务仍发送删除标记。

全息修改操作保留当前通话的执行回执，重复请求不重复创建任务、修改文件或执行工作流；请求 ID 相同而参数不同则拒绝执行。原有文件授权、确认、版本检查与全息风格保持。

配套手机版本 0.10.0 增加 PDF、图片文字及文本附件的本机提取、预览与对话分析，沿用现有中继而无需额外云端配置；同时改进任务搜索，并修复删除确认期间的过期操作及删除保存失败后的回退。请退出旧版后覆盖安装 `DeskBox-2.1.0-hologram.10-Setup.exe`，保留原数据。原生、安装、同步与界面验收使用合成资料，不连接真实项目或付费模型。真实语音及目标设备仍需安装后测试。
