全息 AI 通话改为原生沉浸模式：点击软件内的入口后，直接由投影和下方实时字幕占满当前窗口，不再打开参数面板或额外窗体。

- 首次在「功能与设置 → 全息语音」保存服务、实时模型和密钥，后续进入自动连接。密钥由 Windows DPAPI 加密保存。
- 默认使用有透视纵深、交织光丝与倾斜光环的量子光核。原角色外观可在常规设置选择；通话中没有菜单、参数或工具栏。
- 已移除所有工程场景、场景工具调用、探头演示和场景切换控件。
- 实时声音驱动投影，字幕在投影下更新。Esc 返回软件并释放麦克风；Ctrl+M 静音；中断连接时点击投影重试。
- 尚未配置语音时仍进入纯投影，不弹配置窗口；配置只在常规设置中心出现。

下载 `DeskBox-2.1.0-hologram.2-Setup.exe`，从托盘退出旧版后选择原目录升级。安装保留用户数据，并提供旧 EXE 备份和回退入口。

Windows 10/11 x64，安装器检查 .NET Framework 4.8+。候选包未签名；实时通话需有效密钥、网络和麦克风。原生检查使用模拟语音传输与合成数据，真实付费通话与目标设备 DPI 仍需本机验证。

本版本为私有仓库测试包，下载时需登录有仓库权限的 GitHub 账号。具体检查数与构建链接见附件 `INSTALL-TEST-REPORT.md`。
