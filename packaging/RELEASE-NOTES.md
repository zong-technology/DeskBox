供 Windows 安装、升级和本机实测的全息双风格版本。

**下载 `DeskBox-2.1.0-hologram.1-Setup.exe` 安装。** 仓库为私有仓库，下载时需登录有仓库权限的 GitHub 账号。

- 支持 Windows 10/11 x64；安装器检查 .NET Framework 4.8+。主程序无需 Node、Electron 或浏览器。
- 新电脑默认安装到当前用户目录。已有版本请先从系统托盘退出，再核对并选择原安装目录；已有 `D:\DeskBox\DeskBox.exe` 时会优先选择该位置。
- 升级保留项目、任务、聊天和服务配置，替换前备份旧 EXE。开始菜单和安装目录提供回退入口。重复安装同一程序不会覆盖上一版备份；卸载保留用户数据。
- 软件入口：AI&SI / AI 助手 → 全息 AI 通话 → 预览全息。默认保留银紫龙翼风格，「更改全息风格」可切换星辉光粒子。
- 预览无需麦克风和密钥。实时通话需要可用网络、麦克风、千问或 Gemini 的实时语音模型与密钥；新电脑需要重新配置密钥。文档解析扩展另需 Python 3.12+。

已验证：44 项安装/启动/升级/回退/卸载检查通过；安装后的实际 EXE 再次通过 183 项全息检查；100% / 96 DPI 下，三个窗口尺寸各通过 12 页导航，并捕获三种工作台布局。构建、包内、安装后及实际运行 EXE 哈希一致。全部使用隔离配置和合成数据。

本版本未做应用代码签名，Windows 可能提示发布者无法验证。125%/150% 显示比例、用户历史安装、目标电脑硬件和真实付费语音仍需本机测试。
