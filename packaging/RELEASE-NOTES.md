# DeskBox 4.2.2-tia.3 · 离线工程与安装版验收预览

V20 工程打开时先读只读副本的元数据，读取块正文需另行确认。「测试验证 → 批准新增 FB 并编译」可预览并批准单块 ASCII SCL 草稿。批准绑定源文件内容、目标 PLC 与工程快照。失败作业提供诊断和恢复回执。工程读取、导入及真实编译仍待持许可证的 Windows V20 与授权 `.ap20` 验收。

Windows 10/11 x64，需 .NET Framework 4.8 或更新版本。安装包为未签名预览版。安装回归使用隔离测试资料。

工作台可调整并保存工程树、助手和底部日志比例。顶部「恢复默认布局」会重新保存默认比例。工程语音支持打断、暂停、重连及按授权查询高亮工程对象。账号、麦克风及供应商的真实双向音频仍待目标机验收。

发布附带从已安装进程获取的 12 张工作台截图，以及实际 Windows 版本和 DPI 记录。Microsoft 拼音组字和更高系统缩放仍待目标会话测试。
