# DeskBox V4.1 · 实时语音原型

## 在原 Figma 文件中打开

当前 Figma 连接能读取原文件。Starter 工具调用额度拒绝了本轮写入，原稿未改动，原型链接要等本地导入后生成。

1. 用 Figma 桌面端打开原 DeskBox 设计文件。
2. 在菜单中选择「插件 → 开发 → 从 manifest 导入插件」，选择本目录的 `figma-plugin/manifest.json`。三个插件文件需放在一起。
3. 在该文件运行「DeskBox V4.1 · 语音动效导入」，点击「创建 / 定位原型 Section」。它会在 Business & Voice Prototype 页面添加独立 Section。
4. 插件生成「主线」「打断分支」「减少动效」三个入口。播放主线时，可在探头出现后、感温端高亮前点击麦克风，观察画面回到聆听。打断分支入口也可直接进入讲解画面进行测试。

导入包包含 18 个 1920×1080 状态帧。光丝、粒子、探头、标注、字幕和控制都由可编辑图层组成。标准流程使用 Smart Animate，减少动效流程用即时过渡。导入和原型播放需要在 Figma 中确认。

## 本地预览

直接打开 `实时语音原型.html`。SVG 文件需与 HTML 保持在同一目录。点「播放主线」或「播放打断分支」，勾选「减少动效」可看即时切换。播放期间点麦克风或按 I 可手动打断。字幕和语音阶段均为演示，MP4 无配音。

| 阶段 | 本地演示时间 |
| --- | --- |
| 聆听、开始回答，画面只有本体 | 0–3.85 秒 |
| 字幕提及「温度探头」，本体让位，光丝展开探头 | 3.85 秒起 |
| 感温端高亮 | 5.5 秒起 |
| 切回闲聊，投影开始消散 | 8.55 秒起 |
| 本体回中 | 10.8 秒 |
| 打断分支自动演示打断 | 6.2 秒，之后留在聆听 |

本次对话只涉及温度探头，演示没有整机。探头明确标注「示意」。`keyframes` 存放本地原型截图。

## WinForms 交接

- 使用实际扬声器播放时钟调度语义事件。探头在对应词句开始播放时出现，局部高亮在相应部件被讲到时触发。
- 每轮回复单独管理其语义事件。打断时停止上一轮音频、取消未触发事件、清除该轮投影和高亮，然后进入聆听。应忽略上一轮迟到的事件。
- 用真实麦克风输入或实际播放音频驱动本体的光丝、亮度与粒子。减少动效时保留字幕、标注和控制位置，通过即时状态变化传达同样的信息。
- 有可靠资产时按话题选择整机或部件。只能用通用资产时标注「示意」。没有可用模型时显示本体和文字。
